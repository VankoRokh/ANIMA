# ADR-000 — документация проекта

**Status: Superseded by [ADR-004](ADR-004-documentation-workflow.md).**

## Контекст

Архитектурные идеи находились преимущественно в чатах, README почти отсутствовал. Требовалось перенести контекст в репозиторий, обеспечить возвращение после перерыва, восстановление на другом оборудовании и независимость от памяти помощника.

## Решение первой версии

Документация хранится в `docs` основного репозитория ANIMA. Канонические форматы — Markdown и Mermaid. VS Code используется как основной инструмент, Obsidian — как дополнительная навигация. Введены страницы статуса, карты, реестра модулей, Roadmap, ADR и Operations.

## Результат

Система выполнила исходную задачу: проект получил самостоятельную документацию и проверяемую структуру. Однако практика показала избыточное дублирование текущего состояния и слишком высокую стоимость синхронизации страниц.

Техническая основа ADR-000 сохраняется, а workflow текущего ведения заменён [ADR-004](ADR-004-documentation-workflow.md).
