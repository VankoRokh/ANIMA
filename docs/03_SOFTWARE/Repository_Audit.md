## Что реализовано

Состояние сессий; очередь событий; запись всех событий; отбор непустого user_input; отдельный файл выбранной памяти; чтение сырого журнала; один текстовый ввод и штатный переход sleeping.

## Что отсутствует

Identity (пустой файл), выделенный CLI (пустой файл), модели, цели, эмоции, консолидация, обучение, инструменты, распределённый протокол и аппаратная сборка.

## Проверенный сценарий

Во временной директории на Python 3.12.14 выполнен main.py с одним текстовым вводом и Enter. Результат: штатное завершение, session=1, status=sleeping, три сырых события и одно выбранное воспоминание.

Повторяемая расширенная проверка двух сессий добавляется через scripts/check.sh. Её прохождение не доказывает устойчивость при отключении питания, повреждении JSON, конкурирующих писателях или прерывании процесса.

## Расхождения и технический долг

| ID задачи | Наблюдение | Последствие |
|---|---|---|
| SW-01 | EpisodicMemory читает сырой журнал, хотя CLI называет его памятью | Счётчик и последние записи не отражают выбранный опыт |
| SW-02 | identity.py пуст | Нет уникального экземпляра и версии его схемы |
| SW-03 | state.json перезаписывается напрямую | Сбой может повредить состояние |
| SW-04 | Не проверяются типы payload/text и строки JSONL | Неправильные данные приводят к исключению |
| SW-05 | Прерывание не завершает цикл сна | Может остаться status: awake |
| SW-06 | data зависит от cwd; нет настройки пути | Ручной запуск из другой папки создаёт другое состояние |
| SW-07 | CLI и координация объединены в main.py | Труднее расширять интерфейсы |

Приоритеты и критерии: [Backlog](../06_ROADMAP/Backlog.md).
