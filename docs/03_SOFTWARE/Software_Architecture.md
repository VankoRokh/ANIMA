## Запуск и зависимости

Текущий прототип использует стандартную библиотеку Python: datetime, json, pathlib. Проверка использует дополнительные стандартные модули, не устанавливая внешние пакеты. Подтверждённая среда — Python 3.12.14. Исторический запуск пользователя на Python 3.14.4 не проверялся заново здесь.

setup.sh создаёт локальное окружение; run.sh запускает из корня проекта, чтобы относительный data не зависел от места вызова. У переменной ANIMA_DATA пока нет программной поддержки.

pyproject.toml и lock-файл не добавляются ради пустой зависимости. Они потребуются при появлении внешних пакетов, устанавливаемого проекта или моделей с отдельными требованиями.

## Проверка

check.sh проверяет ссылки и реестр, синтаксис Python и два запуска временного экземпляра с непустым/пустым вводом. Она не читает и не изменяет пользовательский data.

Это проверка базового сценария и развёртывания, а не полный набор тестов отказоустойчивости. Подробности: [Setup](../09_OPERATIONS/Setup.md), [Repository Audit](Repository_Audit.md).
