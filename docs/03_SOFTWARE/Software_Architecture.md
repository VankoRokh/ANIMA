## Запуск и зависимости

Текущий прототип использует стандартную библиотеку Python: datetime, json, pathlib. Проверка использует дополнительные стандартные модули, не устанавливая внешние пакеты. Подтверждённая среда — Python 3.12.14. Исторический запуск пользователя на Python 3.14.4 не проверялся заново здесь.

setup.sh создаёт локальное окружение; run.sh запускает приложение из корня проекта. `main.py` получает каталог экземпляра через `get_data_dir()`, создаёт компоненты и передаёт их в `run_cli()`. Без настройки используется `<project>/data`, `ANIMA_DATA_DIR` может задавать абсолютный или относительный путь, а относительное значение разрешается от корня проекта.

pyproject.toml и lock-файл не добавляются ради пустой зависимости. Они потребуются при появлении внешних пакетов, устанавливаемого проекта или моделей с отдельными требованиями.

## Проверка

check.sh проверяет ссылки и реестр, синтаксис Python, выделение CLI, базовые сценарии экземпляра, отказоустойчивость файлов и конфигурацию каталога данных. Проверка `ANIMA_DATA_DIR` запускает временный экземпляр из разных cwd и проверяет продолжение после копирования каталога. Реальные пользовательские данные она не читает и не изменяет.

Это проверка базового сценария и развёртывания, а не полный набор тестов отказоустойчивости. Подробности: [Setup](../09_OPERATIONS/Setup.md), [Repository Audit](Repository_Audit.md).
