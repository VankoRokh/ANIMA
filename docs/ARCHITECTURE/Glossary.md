# Словарь механизмов ANIMA

**Назначение:** короткое объяснение основных компонентов без чтения исходного кода. Это **карта терминов**, а не новая спецификация контрактов. Действующее поведение нужно уточнять по [тематическим страницам](README.md), реализации и приёмочным тестам.

## Идентичность и работа экземпляра

| Термин | Что означает | Где подробности |
| --- | --- | --- |
| **Identity** | Постоянный идентификатор экземпляра; не равен ID процесса, модели или сессии | [Фундамент](Foundation_Runtime.md) |
| **State** | Долговечные `created/awake/sleeping`, сессии и счётчики | [Фундамент](Foundation_Runtime.md) |
| **Runtime** | Системный цикл, координирующий wake, обработку и sleep | [Фундамент](Foundation_Runtime.md) |
| **CoreAssembly / build_core** | Явная композиция сервисов и опциональных возможностей | [Фундамент](Foundation_Runtime.md) |
| **EventBus** | Очередь событий внутри работающего процесса; не долговечная база сама по себе | [Фундамент](Foundation_Runtime.md) |
| **Event / EventLog** | Отдельный факт получения/наблюдения и долговечный первичный журнал `events.jsonl` | [Память](Memory_and_Retrieval.md) |
| **Source / Producer** | Сведения об источнике и адаптере; строковая метка сама не аутентифицирует отправителя | [Исполнение и допуск](Execution_and_Verification.md) |
| **CoreIngress** | Типизированный допуск событий от зарегистрированных источников | [Исполнение и допуск](Execution_and_Verification.md) |
| **Belief** | Системное представление допустимых наблюдений об определённом свойстве; не память разговоров | [Исполнение и допуск](Execution_and_Verification.md) |

## Память и доступ к информации

| Термин | Что означает | Где подробности |
| --- | --- | --- |
| **Memory** | Производное представление эпизода или опыта; не заменяет raw Event | [Память](Memory_and_Retrieval.md) |
| **MemoryProcessor** | Выбор, группировка, обновление и связывание эпизодов | [Память](Memory_and_Retrieval.md) |
| **Composer** | Ограниченное текстовое представление опыта; может опускать исходные детали | [Память](Memory_and_Retrieval.md) |
| **Knowledge** | Утверждение с собственным статусом и основаниями; не любое сообщение пользователя | [Память](Memory_and_Retrieval.md) |
| **Entity / Relation** | Якоря и связи между объектами; не обязуют применять GraphDB | [Память](Memory_and_Retrieval.md) |
| **Provenance / Evidence** | Возможность проследить утверждение или эпизод до конкретных источников | [Память](Memory_and_Retrieval.md) |
| **EventRetrieval** | Производный FTS5-индекс исходного журнала; различает полную и частичную индексацию | [Память](Memory_and_Retrieval.md) |
| **RetrievalEngine** | Поиск по Memory/Knowledge и связям с детерминированными фильтрами и ranking | [Память](Memory_and_Retrieval.md) |
| **ContextBuilder / ContextBundle** | Отбор ограниченного доказательного контекста для конкретного потребителя | [Память](Memory_and_Retrieval.md) |
| **Shadow Encoding** | Альтернативная экспериментальная группировка; не заменяет автоматически рабочий MemoryProcessor | [Исследования](../RESEARCH/README.md) |

## Цели, состояние и когнитивная обработка

| Термин | Что означает | Где подробности |
| --- | --- | --- |
| **Goal** | Долговечная цель и её критерий успеха, не конкретная инструкция инструменту | [Внутреннее состояние](Internal_State_and_Goals.md) |
| **Task / TaskStore** | Долговечная единица работы и история переходов; Goal и Task независимы | [Исполнение](Execution_and_Verification.md) |
| **Internal State** | Ограниченные регуляторы `fatigue`, `uncertainty`, `frustration`, `satisfaction` | [Внутреннее состояние](Internal_State_and_Goals.md) |
| **TransitionEngine** | Версионированные изменения внутреннего состояния с причиной | [Внутреннее состояние](Internal_State_and_Goals.md) |
| **Candidate / ChoiceEngine** | Проверенные варианты и их системная оценка; состояние может менять оценку, но не полномочия | [Внутреннее состояние](Internal_State_and_Goals.md) |
| **Canonical IR / CanonicalTask** | Нормализованная форма задачи, отделённая от текста LLM | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **Resolver** | Детерминированно решает формальную часть и классифицирует оставшееся | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **Projection** | Ограниченное представление задачи и контекста для выбранного backend | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **FAST / DEEP** | Разные роли заменяемых когнитивных обработчиков; не отдельные личности | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **CognitiveRouter** | Системный выбор между FAST, DEEP, CHOICE и отказом до вызова модели | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **CognitiveProposal** | Неполномочное предложение модели, нуждающееся в валидации | [Когнитивный контур](Cognition_FAST_DEEP.md) |
| **AgentRun / PlannerAdapter** | Исторический эксперимент Stage 4, не современный владелец системного цикла | [Stage 4](../STAGES/04_Agent_Experiment.md) |

## Статусы разработки

**`Stage Complete`** — приняты старые критерии конкретного этапа. **`Validated Lab`** — подтверждён ограниченный эксперимент. **`Integrated`** — модуль включён в заявленный путь исполнения. **`Release Accepted`** — зафиксированный релизный снимок прошёл [свой контракт](../RELEASES/ANIMA_v0_1_Release_Contract.md). Это разные доказательные уровни.

**Принцип:** сначала определить источник, владельца состояния и полномочия, затем проверять поведение. Текстовая схожесть или зелёный тест интерфейса сами по себе не дают права на исполнительное действие.
