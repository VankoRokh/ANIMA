# История разработки ANIMA

**Назначение:** объяснить, как менялась система и почему некоторые направления были остановлены, а другие вошли в позднюю сборку. Это не текущий релизный Roadmap.

## Основная последовательность

[Хронология Stage D0–11](stages.md) содержит для каждого этапа задачу, созданные механизмы, границы проверки и наследие. Статусы первоначального плана получаются из [исторического `project.json`](../project.json) и не являются статусами выпуска.

## После Stage 6 — параллельные линии

| Линия | Что изменилось | Где доказательства |
| --- | --- | --- |
| [Typed Core v0.1](core-v0.1.md) | P0–P4, независимый аудит B1–B4, исправления, адаптер P5/P6 | Привязка к `aabe655…`, `b639a52…` и профильным негативным тестам |
| [Memory Integration](memory-integration.md) | EXP-009, raw EventRetrieval, M0–M6-B2, релизный bounded Context | A/B/C/D и C3; изолированные approval и Godot сценарии |
| [Stage 7](stages.md#stage-7) | Read-only semantic boundary и conformance | Первичные TV-0052/53, отдельные открытые DP |
| [ANIMA v0.1 Foundation](../versions/v0.1/contract.md) | Состав непрерывного детерминированного экземпляра | [Приёмка](../versions/v0.1/acceptance.md) по SHA |

**Не путать:** завершённый Stage, успешный лабораторный gate, подключённый production-механизм и принятое релизное требование. Сведения о текущей версии — только в [`versions/`](../versions/README.md).

## Дальнейшие источники

[Исходные TV-0001–TV-0054](../TESTING/Results/README.md) сохраняют статус на момент прогона, [ADR](../DECISIONS/README.md) — причины решений, [архивные снимки](../ARCHIVE/Development_Snapshots.md) — прежние редакции. Старые документы `STAGES/`, `ROADMAP/` и `ARCHITECTURE/` остаются доступными до окончания безопасной миграции.
