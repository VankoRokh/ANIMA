# Эксперименты

Гипотеза не становится частью принятой архитектуры до результата и решения. Все три начальные записи ниже — **Planned**; измерений и выводов пока нет.

Статусы: Planned, Active, Successful, Failed, Inconclusive. Отрицательные и неопределённые результаты сохраняются.

## EXP-001

**Эмоциональный вес и полезность памяти.**

- Гипотеза: внутренние оценки могут улучшить отбор полезных воспоминаний при ограниченном объёме.
- Условия старта: корректное чтение выбранной памяти, фиксированный набор примеров, минимальные внутренние переменные.
- Метод: одинаковый набор и лимит памяти; сравнить простой отбор/ранжирование и вариант с дополнительным эмоциональным весом.
- Метрики: качество извлечения по заранее размеченным запросам, сохранение источников, объём и стоимость обработки.
- Риск: эмоциональная интенсивность может усиливать ошибки и нерелевантный опыт.
- Результат и вывод: не получены.
- Статус: Planned.

Связи: [MEM-08](../02_ARCHITECTURE/Memory.md#mem-08), [Emotions](../02_ARCHITECTURE/Emotions.md), [Stage 1](../06_ROADMAP/Stage_1_Memory.md).

## EXP-002

**Адаптация Fast во время фоновой обработки.**

- Гипотеза: отобранный опыт может улучшать ответы Fast.
- Условия старта: выбран Fast, фиксирована базовая версия и есть независимый контрольный набор.
- Метод: отдельно сравнить изменение контекста/правил и обучение весов; параметры обработки фиксируются.
- Метрики: качество на новых примерах, задержка, RAM, энергия, время обновления и регрессии.
- Риск: анализ Deep может содержать ошибки; обучение может не укладываться в аппаратный бюджет.
- Ожидаемое решение: принять полезный вариант только после сравнения и проверки отката.
- Результат и вывод: не получены.
- Статус: Planned.

Связи: [SLP-03](../02_ARCHITECTURE/Sleep.md#slp-03), [Fast / Deep](../02_ARCHITECTURE/Fast_Deep.md).

## EXP-003

**Локальная оптимизация периферии.**

- Гипотеза: для одной конкретной задачи периферии локальное подкрепление может улучшить результат.
- Условия старта: выбранная задача и симуляция или проверяемый ограниченный стенд.
- Метод: сравнить простое управление с локальной оптимизацией на одинаковых сценариях.
- Метрики: ошибка, время, ресурс и поведение при отказе.
- Граница: эксперимент не вводит глобальную систему награды для личности.
- Результат и вывод: не получены.
- Статус: Planned.

Связи: [ADR-003](../08_DECISIONS/ADR-003-local-reinforcement.md), [Hardware](../04_HARDWARE/Hardware_Architecture.md).
