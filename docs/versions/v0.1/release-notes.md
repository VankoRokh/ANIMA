# ANIMA v0.1 Foundation — заметки к первому релизу

**Версия принята владельцем: 15 ноября 2026 года.** Релизный код: `0c334a0cc51782eb460028f643ba7c2b83d5e821`. Имя тега для публикации: `v0.1` (**наличие опубликованного Git ref подтверждается отдельно**).

## Что входит

**ANIMA v0.1 Foundation** — локальный детерминированный фундамент автономного агента, не чат-бот и не законченная универсальная когнитивная система. Без обязательных LLM, Godot, Raspberry Pi, сети и периферии.

- Сохраняемая **Identity** и перезапуск экземпляра.
- **EventLog** с raw Events, индексированным **Event Retrieval** и **Provenance**.
- Эпизодическая **Memory** с консервативными правилами ассоциации; ограниченный `ContextBundle`.
- Раздельные **Goal/Task**, **Policy**, **Execution** и **Verification** в предусмотренных профилях.
- Восстановление после программных прерываний и соблюдение идемпотентности в проверенных сценариях.
- Изолированная SQLite-песочница действий, подключаемая только через `--sandbox-door`.
- Документация на русском с исходными названиями технических компонентов, стабильная структура проекта и проверенные тесты.

### Быстрый запуск

В Linux / Python 3.12+ из checkout релизного тега:

```bash
python3 -m venv .venv
.venv/bin/python -m anima.release_v01 --data-dir /tmp/anima-v01-instance
```

`release_v01` принимает JSONL-команды `report`, `search_events`, `context`, `status`, `stop`. Пример команды ввода: `{"op":"report","text":"Первое событие ANIMA"}`. Каталог данных — **отдельный экземпляр**, его нельзя помещать в Git. Полные инструкции: [эксплуатация](../../operations.md).

## Известные ограничения

- **Memory — не полная семантическая память**. Объединение эпизодов основано на эвристиках; `Memory.content` ограничен 512 символами, Context может опускать исходные факты. Raw Events остаются доступны отдельно.
- Нет доказанного SLO для 10⁵ событий, другого оборудования или параллельной нагрузки. Ресурсный норматив фиксирован для одного сценария ноутбука.
- Реальный power-loss, Pi и физические датчики не входят в выполненный релизный gate.
- FAST/DEEP LLM, расширенный SLEEP, Knowledge Stage 7, Godot и большая архитектура L2 **не являются обязательным исполнением v0.1**.
- Миграция прежних смешанных Memory не выполняется автоматически.
