# Версии ANIMA

Здесь находятся **контракты выпусков**, доказательства на конкретных Git SHA и решения о принятии. Исторические Stage и лабораторные PASS не становятся автоматически частью релиза.

## ANIMA v0.1 Foundation — кандидат

[Контракт v0.1](v0.1/contract.md) фиксирует требования `R-01–R-10`, базовую сборку, отдельный sandbox и границы полномочий. [Карточка приёмки](v0.1/acceptance.md) — фактические проверки, SHA и открытые `R-09/R-10`. [Принятый R-08](v0.1/resources.md) — ресурсный норматив, локальные JSON, ограничение Memory и будущие исследования. [Дорожная карта](../roadmap.md) содержит только актуальные действия до решения о выпуске.

**Источники:** [неизменяемое ноутбучное свидетельство](../RELEASES/ANIMA_v0_1_Notebook_Evidence.md) и [исторический Gap Audit](../RELEASES/ANIMA_v0_1_Gap_Audit.md) описывают свои моменты и не заменяют карточку версии.

## Будущие релизы

Не объявлены, версии, даты и обязательные функции не назначены. Исследовательские направления — в [каталоге исследований](../RESEARCH/README.md); история уже сделанного — в [хронологии](../history/stages.md).
