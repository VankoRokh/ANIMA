# Версии ANIMA

Здесь находятся **контракты выпусков**, доказательства на конкретных Git SHA и решения о принятии. Исторические Stage и лабораторные PASS не становятся автоматически частью релиза.

## ANIMA v0.1 Foundation — принят 15 ноября 2026

[Контракт v0.1](v0.1/contract.md) фиксирует требования `R-01–R-10`, базовую сборку, отдельный sandbox и границы полномочий. [Карточка приёмки](v0.1/acceptance.md) — фактические проверки, принятые R-01–R-10 и точный SHA. [Релизные заметки](v0.1/release-notes.md) — возможности, ограничения и опубликование тега. [Принятый R-08](v0.1/resources.md) — ресурсный норматив, локальные JSON, ограничение Memory и будущие исследования. [Дорожная карта](../roadmap.md) фиксирует завершение v0.1 и открытые направления будущих исследований.

**Источники:** [неизменяемое ноутбучное свидетельство](../RELEASES/ANIMA_v0_1_Notebook_Evidence.md) и [исторический Gap Audit](../RELEASES/ANIMA_v0_1_Gap_Audit.md) описывают свои моменты и не заменяют карточку версии.

## Будущие релизы
