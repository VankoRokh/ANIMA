# Версии ANIMA

Здесь находятся **контракты выпусков**, доказательства на конкретных Git SHA и решения о принятии. Исторические Stage и лабораторные PASS не становятся автоматически частью релиза.

## ANIMA v0.2 RC1 — принят к Release Candidate 19 ноября 2026

[Контракт v0.2 RC1](v0.2/contract.md) фиксирует только проверенный детерминированный Memory/Knowledge/Context профиль, доверенные Memory writers и Retrieval adapters и границы O58-01/O58-02. [Карточка приёмки](v0.2/acceptance.md) содержит исходный SHA, результаты R8 и независимый H5.8 **PASS / APPROVE_RC**. [Релизные заметки](v0.2/release-notes.md) описывают доступные функции и ограничения. [Запись о публикации](../RELEASES/ANIMA_v0_2_RC1_Release_Record.md) фиксирует Git tag и GitHub Pre-release.

**Владелец допустил кодовый SHA `1364e62634669ef553df0b2f2d7a1159d404383f` к RC.** Аннотированный Git tag `v0.2.0-rc.1` опубликован на проверенном SHA. GitHub Pre-release [опубликован](https://github.com/VankoRokh/ANIMA/releases/tag/v0.2.0-rc.1); редакционные документы на отдельной ветке не являются частью проверенного дерева. Это **не** stable v0.2 и не утверждённая готовность недоверенных когнитивных компонентов.

## ANIMA v0.1 Foundation — принят 15 ноября 2026

[Контракт v0.1](v0.1/contract.md) фиксирует требования `R-01–R-10`, базовую сборку, отдельный sandbox и границы полномочий. [Карточка приёмки](v0.1/acceptance.md) — фактические проверки, принятые R-01–R-10 и точный SHA. [Релизные заметки](v0.1/release-notes.md) — возможности, ограничения и опубликование тега. [Принятый R-08](v0.1/resources.md) — ресурсный норматив, локальные JSON, ограничение Memory и будущие исследования. [Дорожная карта](../roadmap.md) фиксирует завершение v0.1 и открытые направления будущих исследований.

**Источники:** [неизменяемое ноутбучное свидетельство](../RELEASES/ANIMA_v0_1_Notebook_Evidence.md) и [исторический Gap Audit](../RELEASES/ANIMA_v0_1_Gap_Audit.md) описывают свои моменты и не заменяют карточку версии.
