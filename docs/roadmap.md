## После RC1 — планирование следующей версии

**Номер, объём, сроки и приёмочные критерии следующего выпуска пока не установлены.** Новый release contract и дорожная карта создаются только после отдельного решения.

Основные кандидаты для исследований:

- **Identity/authority of Evidence:** O58-01 — различение нового Memory ID, новых Raw Event IDs, версий и независимых источников; сложные случаи split/merge без искусственной дедупликации.
- **Canonical Context projection:** O58-02 — проверка, что LLM/tool adapter не может выдать под настоящим ID изменённый текст Memory, явные правила конфликтующих records и граница trusted/untrusted adapters.
- **Memory:** очистка служебной разметки, более качественная консолидация `Memory.content` (сейчас ограничение 512 символов), оценка полноты `Context`, поиск без явных тематических префиксов, миграция ранее смешанных эпизодов.
- **Когнитивные модули:** независимые FAST/DEEP и SLEEP-переработка без передачи им полномочий Core.
- **Интеграции:** аппаратное исполнение на Raspberry Pi, Godot/VAL, источники восприятия — каждый со своими контрактами и тестами.
- **Масштабирование:** продолжительные тесты производительности, большие базы Events/Memory, устойчивость к реальным сбоям питания.

Это **направления**, не утверждённые обязательства следующей версии. Исследования находятся в [каталоге](RESEARCH/README.md); [история Stage](history/stages.md) и [старые Roadmap](ROADMAP/README.md) сохраняются без ретроактивного переписывания.

## Правило дальнейшей разработки

Новый контракт → ограниченный эксперимент → воспроизводимые доказательства → проверка границ Core и источников → регрессия → решение о включении в релиз. Первичные данные, Git tag и уже принятые SHA не переписывать.
