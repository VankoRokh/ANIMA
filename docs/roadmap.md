# Дорожная карта ANIMA v0.1 Foundation

**Актуальность: 14 ноября 2026 года.** Здесь находятся только открытые действия для выпуска текущей версии. Старый `docs/project.json` описывает исторические Stage и не управляет релизным статусом. В [истории](history/stages.md) его данные сохраняются без переписывания.

## Цель

Принять воспроизводимый детерминированный экземпляр ANIMA с Identity, Events, Memory, bounded Context, сохранением источников, ограниченными Goal/Task и восстановлением. Базовый профиль не требует LLM, Godot, Raspberry Pi или датчиков; действие в SQLite-мире требует явного `--sandbox-door` и отдельного каталога данных.

**Единственный нормативный источник объёма версии:** [R-01–R-10](RELEASES/ANIMA_v0_1_Release_Contract.md). [Текущая карточка доказательств и решения](versions/v0.1/acceptance.md).

## Что не является блокером выпуска

Stage 7 write/revision, E4/L2, обязательный Godot/VAL, Raspberry Pi, FAST/DEEP LLM и расширенный SLEEP не входят в обязательный базовый контур. Их прогресс и ограничения объясняются в [исследованиях](research/README.md), а [история Stage](history/stages.md) не служит графом зависимостей этого релиза.

## Порядок работы

Реализация и лабораторные результаты остаются в своих источниках; для выпуска используем **контракт → конкретный gate → состояние checkout/SHA → решение владельца**. После выбора объёма следующей версии создаётся новый отдельный план. Старые адреса `docs/ROADMAP/` продолжают работать через [совместимый указатель](ROADMAP/README.md).
