# Stage 6.3 Goals, Internal State and Action Choice

## Цель

Подтвердить system-owned выбор между уже допустимыми action candidates через существующие Goal и Internal State contracts, не передавая FAST/DEEP право выбирать или исполнять действие.

## Условия

Проверенный snapshot: `f388d87feb89caf1032df9bba73cebff3104be61` в ветке `work/stage6-cognitive-integration`.

Используется существующий Stage 2 `ChoiceEngine`; Stage 6 добавляет только интеграционный `ActionChoiceCoordinator`. Action-choice capability в `CognitiveRouter` остаётся opt-in и по умолчанию выключена.

## Сценарий и входные данные

Проверены:

- active persistent Task, связанный с active Goal;
- `CHOOSE_ACTION` CanonicalTask с несколькими candidates;
- hard constraints проходят через Stage 5 resolver до Choice;
- Choice допускается только для `multiple_actions_without_policy`;
- system Candidate IDs обязаны точно совпадать с `resolution.remaining`;
- neutral Internal State сохраняет baseline ranking;
- bounded state modifiers могут измеримо изменить выбор;
- trace сохраняет baseline candidate, selected candidate, state snapshot и score modifiers;
- malformed/unsupported constraints и formal policy conflicts не передаются Choice;
- отсутствующий Goal, inactive Goal, inactive Task и mismatched candidates отклоняются;
- Task и Goal не мутируют самим выбором;
- FAST/DEEP не вызываются для system-owned Choice path;
- старый Stage 6.2 baseline остаётся закрытым по умолчанию без `enable_action_choice=True`.

Команды проверки включали targeted `tests/test_stage6_action_choice.py`, `tests/test_cognitive_routing.py`, `tests/test_choice_engine.py`, project checks и полный `.venv/bin/python -m pytest -q`.

## Ожидаемый результат

Internal State влияет только на score уже существующих допустимых candidates через явные bounded правила; Goal остаётся authority для смысла работы; resolver остаётся authority для hard constraints; модель не получает права выбрать action напрямую.

## Фактический результат

Targeted проверки, project checks и полный regression suite прошли успешно на указанном snapshot.

## Метрики

Stage 6.3 не вводит performance SLA. Ключевые метрики: deterministic baseline воспроизводим; state modifier contribution ограничен ruleset; изменение выбора причинно реконструируется из trace; regression suite остаётся зелёным.

## Доказано

Актуальный Stage 6 cognitive loop может использовать persistent Goal и bounded Internal State как причинно наблюдаемые факторы system-owned action selection. `Goal ≠ Task ≠ Candidate ≠ Action`, а FAST/DEEP не приобретают execution authority.

## Не доказано

Stage 6.3 не доказывает side-effect execution, independent environment observation, Goal verification после execution, Sleep lifecycle integration или restart recovery уже выполненного действия. Это последующие slices Stage 6.
