# Stage 4.6 Candidate Adaptation / Choice Integration

## Цель

Подтвердить системную границу `ActionProposal → Candidate → ChoiceEngine`: Planner rank даёт только ограниченное базовое предпочтение, а effort/risk/information gain/history-derived признаки вычисляются ANIMA вне Planner; существующий Stage 2 ChoiceEngine применяет Internal State и выбирает proposal без изменения своего контракта.

## Условия

Проверка выполнена владельцем проекта после получения изменений из `main` на snapshot `aa2594058bec8aa0a9d526636761146f702fb58c`. Использованы существующий Stage 2 `ChoiceEngine`, системные `ToolDescriptor` и deterministic proposal history; сам ChoiceEngine не изменялся.

## Сценарий и входные данные

Выполнены targeted `tests/test_agent_choice_integration.py`, полный regression suite и `scripts/check.sh`. Targeted suite проверяет bounded planner-rank preference, system-owned effort/risk/information-gain признаки, canonical proposal fingerprint, trusted repeated failure/verified continuation history и интеграцию с neutral/altered Internal State.

## Ожидаемый результат

Planner не может занизить risk/effort, объявить собственный success или обойти Choice. Один набор proposals при neutral state сохраняет ограниченное предпочтение Planner, а при изменённом Internal State может дать другой системно объяснимый выбор через существующий Choice trace.

## Фактический результат

Владелец проекта подтвердил успешное прохождение targeted Candidate/Choice integration suite, полного regression suite и `scripts/check.sh` на указанном snapshot. Ошибок Stage 4.6 не обнаружено.

## Метрики

Отдельный performance baseline на 4.6 не требуется. Функциональные проверки: targeted Candidate Adaptation / Choice Integration suite — Passed; полный regression suite — Passed; `scripts/check.sh` — Passed.

ActionProposal преобразуется в существующий Stage 2 Candidate с сохранением identity `ActionProposal.id == Candidate.candidate_id`; Planner rank имеет ограниченное влияние; Tool metadata и trusted history определяют системные Candidate features; Internal State влияет на итоговый выбор только через ChoiceEngine и не передаётся Planner.

## Не доказано
