# Stage 6.5 Sleep Lifecycle Integration

## Цель

Подтвердить persistent связь Task ↔ Goal ↔ SleepJob поверх уже доказанного Stage 3 Sleep runtime, безопасное interruption/wake/resume и отсутствие повторения committed side effect через Sleep/restart boundary.

## Условия

Проверенный snapshot: `207bc42ed10128036050dd9c1b11c58e55d167d4` в ветке `work/stage6-cognitive-integration`.

Stage 3 `sleep.db` и его contracts не изменялись. Stage 6 использует отдельный `task_sleep.db` только для долговечной связи Task ↔ Goal ↔ SleepJob и фазы межмодульного lifecycle.

## Сценарий и входные данные

Проверены:

- active Task → interrupted при входе в Sleep;
- persistent TaskSleepLink переживает reopen/restart;
- SleepJob выполняет bounded chunk и checkpoint;
- wake возвращает Task в active, не теряя resumable SleepJob;
- тот же Task повторно входит в тот же interrupted SleepJob;
- checkpoint resume продолжает с сохранённой sequence и завершает derived result;
- завершённый SleepJob закрывает TaskSleepLink при wake;
- restart в checkpointed Sleep восстанавливает sleeping link, interrupted Task и активный SleepJob;
- Sleep блокируется при execution operation в prepared/executing/uncertain;
- succeeded keyed side effect не повторяется после Sleep/wake;
- существующие Stage 3 Sleep runtime, Stage 6.4 execution и TaskStore regression tests остаются зелёными.

## Ожидаемый результат

Task и Goal сохраняют ownership и lifecycle через Sleep; bounded Sleep work может checkpoint/resume через несколько sleep/wake циклов; restart восстанавливает связь; unresolved execution side effect не пересекает Sleep boundary; committed keyed effect не дублируется.

## Фактический результат

Targeted Stage 6.5 tests, Stage 3 Sleep regression, Stage 6.4 execution regression, project checks и полный pytest suite прошли успешно на указанном snapshot.

## Метрики

Acceptance является correctness/recovery baseline без performance SLA: zero lost Task/Goal references; zero duplicate committed keyed writes; checkpoint resume начинает с ожидаемой sequence; полный regression остаётся зелёным.

Stage 6 имеет restart-safe Task ↔ Sleep lifecycle поверх существующего Stage 3 runtime без миграции его schema. Sleep остаётся system mode и bounded processing lifecycle, а не отдельной моделью или владельцем cognition.
