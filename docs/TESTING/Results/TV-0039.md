# Stage 4.9 Agent Events / Experience Capture

## Цель

Подтвердить, что значимый опыт AgentRun публикуется как компактная причинная цепочка `agent.*` Events без копирования полного execution history и без дублирования при replay/crash-reconciliation.

## Условия

Проверка выполнена владельцем проекта после получения исправления targeted test на snapshot `a39615ee1faf89a82ece78718cce7117a4bcc86b`. Использован canonical Stage 4 AgentLoop и append-only `EventLog`; publication intent хранится отдельно в `agent.db`.

## Сценарий и входные данные

Выполнены targeted `tests/test_agent_events.py`, полный regression suite и `scripts/check.sh`. Canonical run содержит ошибочное чтение, смену стратегии, обратимую запись, независимый readback и проверенное завершение Goal. Дополнительно проверяются replay, конфликт содержимого и crash между append raw Event и фиксацией publication status.

## Ожидаемый результат

Публикуются только смысловые `agent.failure`, `agent.strategy_change`, `agent.action`, `agent.observation`, `agent.result`; большие/raw Tool payload не копируются; stable publication key сохраняет один `ev_...`; повтор и crash recovery не создают второй Event; несовпадающее содержимое с тем же key отклоняется.

## Фактический результат

Владелец проекта подтвердил успешное прохождение targeted Agent Events suite после исправления ложноположительной проверки теста, затем полного regression suite и `scripts/check.sh`. Ошибок Stage 4.9 на указанном snapshot не осталось.

## Метрики

Отдельный performance baseline на 4.9 не требуется. Функциональные проверки: targeted Agent Events / Experience Capture suite — Passed; полный regression suite — Passed; `scripts/check.sh` — Passed.

## Доказано

Agent operational history может быть отфильтрована в компактную причинную цепочку значимого опыта; publication intent резервирует stable Event ID до append; replay и crash reconciliation не размножают raw Events; Event payload остаётся компактным и связан с Run/Goal/Step/Action/Observation/Verification через references.

## Не доказано

4.9 не доказывает формирование долговременной episodic Memory, повторное использование опыта следующим Goal, полный AgentRun restart/replay или recovery незавершённых structured artifacts. Эти свойства относятся к 4.10–4.11 и финальной валидации Stage 4.
