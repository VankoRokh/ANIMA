## Ожидаемый результат

`output_contract="text"` проверяется как semantic projected delivery: уникальный
`COBALT47` присутствует в raw model response и final response, projected view
совпадает с реально отправленным view, native prompt доставлен без подмены,
backend/model response не ремонтируется; ровно 1 attempt / generation / completion.
Ответ только `text`, `candidate` или `output_contract` вместо task content провален.
`COBALT47.` допустим. Stage 5 не гарантирует byte-exact formatting unrestricted
text output: для этого нужен будущий explicit output contract или constrained
decoding, вне текущего scope. Это не изменение production validation.

Candidate-mode по-прежнему требует точного разрешённого ID: `CONTINUE.` и
`RESULT=CONTINUE` отклоняются без repair и retry. Hard constraints применяются
до policy и до проекции. Deterministic / insufficient routes не вызывают backend.

## Доказано

Exact decimal arithmetic/threshold equality, genuine missing-data handling,
unknown versus known-empty candidates, constraints before ACTION_PRIORITY,
conflict handling и uniform final validation проходят deterministic regressions.
Raw unresolved preferences/textual evidence сохраняются в projection; legacy и
projected backend capabilities разделены. Попытки, успешные completions и terminal
failures различимы. Deterministic и insufficient routes имеют zero backend attempts.
Source-copy tests исключают .venv-*, private artifacts и external symlinks, сохраняя
pending source additions и текущие tracked edits. Real projected transport передаёт
task content модели и сохраняет её ответ; candidate rejection и failure propagation
работают end-to-end. Prompt исправления не маскируются output repair.

## Не доказано

Это integration smoke, не benchmark intelligence, independent memory recall,
универсальная model reliability или byte-exact free-text guarantee. Повторяемость
не гарантируется между версиями модели/runtime. Локальный raw evidence не входит
в Git; portable representative evidence сохранён в этом отчёте.

Semantic persistence/write/update/revision, temporal lifecycle, DEEP,
Agent/Planner/Tools/Executor, Sleep, Internal State decisions, broad NL parsing,
data acquisition и general response rendering остаются вне scope.
Перед объявлением Completed нужны review/acceptance этого отчёта и отдельная
финальная синхронизация status/focus документации; в этом pass они не выполняются.
