# Stage 7 Semantic Boundary Deterministic Baseline Validation

## Цель

Подтвердить первую read-only реализацию `classify_relation/0.1`: строгий protocol/semantic validator, deterministic reference evaluator и conformance harness поверх owner-reviewed Stage 7 corpus без подключения model backend и без lifecycle/Knowledge writes.

## Условия

Проверка выполнена на snapshot `ccb0fe72fb6686042bf5853489eda1e28e96981d` ветки `work/stage7-semantic-boundary-v0` после фиксации semantic boundary, wire schema, 50 owner-reviewed root cases и canonical JSON fixtures.

Пользователь выполнил полный pytest regression и `scripts/check.sh`; обе проверки завершились успешно.

## Сценарий и входные данные

Conformance corpus содержит 50 root cases для `classify_relation/0.1`, сгруппированных по шести семантическим блокам:

1. atomic CONTENT;
2. temporal semantics;
3. REVISION/correction;
4. Evidence identity/replay/dependence;
5. comparability/insufficiency/capability;
6. protocol/security boundary.

Reference evaluator получает только валидированные typed records. Он не пишет Knowledge, не выбирает lifecycle action, не назначает source authority и не вызывает LLM.

Protocol-invalid roots проверяют preflight/parse/schema/referential-integrity failures отдельно от semantic Assessment.

## Ожидаемый результат

Все deterministic-decidable и process/preflight cases должны завершаться без model backend. Только заранее определённые language-semantic residual cases могут требовать backend call.

Evaluator должен совпасть с owner-reviewed gold fixtures по каждому полностью deterministic root case. Для residual cases уже определённые facets должны совпасть с gold и не могут быть переписаны будущей моделью.

Полный regression проекта должен остаться зелёным.

## Фактический результат

Все проверки завершились успешно.

Conformance harness подтвердил структуру corpus и deterministic/reference поведение. После исправления представления terminal Evidence grounds для derived evidence CR-039/CR-040 совпали с принятым gold: upstream premise остаётся в provenance/dependency graph и не дублируется как отдельный facet ground.

Дополнительно исправлен test source snapshot: документированные JSON schema resources теперь сохраняются во временных test-repositories, не ослабляя проверки broken links. Отдельный regression test подтверждает это поведение.

## Доказано

- frozen `classify_relation/0.1` root corpus может быть обработан строгим typed validator/reference evaluator;
- deterministic-first boundary реально уменьшает model-facing workload;
- CONTENT и REVISION остаются независимыми facets;
- protocol/process failures отделены от semantic outcomes;
- exact numeric/unit normalization работает без float coercion для покрытых reference units;
- temporal `Unknown`, partial intervals, overlap и ordered succession различаются детерминированно в покрытом v0 scope;
- unsupported capability отличается от insufficient information;
- upstream derivation premises сохраняются в provenance/dependency, но не раздувают terminal facet grounds;
- deterministic results не зависят от confidence, recency или source authority;
- существующие regressions предыдущих Stage сохранены.

## Не доказано

- качество model residual на реальной FAST-модели;
- устойчивость model-facing renderer/prompt к более широкому residual corpus;
- constrained decoding/grammar integration;
- LoRA/SFT необходимость или полезность;
- lifecycle write/update/revision semantics для Knowledge;
- descendant reevaluation/dependency propagation policy;
- production dispatcher/wiring для `classify_relation/0.1`.

Эти вопросы остаются следующими шагами Stage 7.

## Итог

Deterministic baseline Stage 7 принят как проверенный. Для текущих 50 root cases только два требуют language-semantic model residual, тогда как остальные 48 завершаются полностью системным deterministic/preflight слоем без LLM.

Следующий шаг — построить bounded model-facing residual path для `CR-028` и `CR-032`, сохранив system-owned validation и запрет модели переписывать уже определённые deterministic facets.
