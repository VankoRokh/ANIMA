# Stage 6.7 Mini Experiments

## Цель

Получить воспроизводимое evidence по трём ограниченным вопросам Stage 6 без автоматического изменения production authority: system-mediated `request_more_context`, bounded FAST/DEEP routing baseline и причинное влияние Internal State на Choice.

## Условия

Проверенный experimental snapshot: `0a1692ffaeea66ad8c25fbafd1294d5fe829c3b6` в ветке `work/stage6-cognitive-integration`.

Experiment harness изолирован от production `CognitiveRouter`, `ProposalValidator` и Choice rules. В отчёте явно сохранено, что `request_more_context`, adaptive routing и изменение Choice rules не включены в production.

Для сравнения FAST/DEEP используется только model-dependent часть Stage 5 Benchmark v2: positive model checks `4/4` для Qwen3-0.6B и `4/4` для SmolLM3-3B. Общий `8/8` не используется как measure качества модели, поскольку включает zero-call deterministic cases и injected validation case.

## Сценарий и входные данные

### EXP-004 — Request more context

Controlled fixture начинается с bounded context без target knowledge и допускает максимум один дополнительный system-mediated retrieval.

Фактический результат:

- initial coverage: `0.0`;
- final coverage: `1.0`;
- coverage delta: `+1.0`;
- backend calls: `2`;
- additional retrievals: `1`;
- second context-request loop не возник;
- final proposal: `RESPOND`;
- final response: `COBALT47`;
- mechanism verdict: **Accepted**;
- real LLM answer-quality verdict: **Inconclusive**.

Вывод: bounded system-mediated mechanism технически полезен на controlled fixture, но этого недостаточно для включения production `REQUEST_CONTEXT`; реальная польза для FAST/DEEP должна измеряться отдельно на model-backed workload.

### EXP-005 — FAST/DEEP routing baseline

Четыре controlled cognitive cases дали baseline routing:

- bounded open task → FAST;
- high-uncertainty open task → FAST;
- conflicting structured fact → DEEP;
- explicit conflict reasoning → DEEP.

Адаптивный кандидат, который дополнительно отправляет high-uncertainty open task в DEEP, увеличил число DEEP calls с `2` до `3` без наблюдённого model-quality преимущества на имеющемся benchmark evidence.

Benchmark reference:

- Qwen3-0.6B: `4/4` positive checks, mean backend latency `2054 ms`;
- SmolLM3-3B: `4/4` positive checks, mean backend latency `12753 ms`;
- DEEP/FAST latency ratio: `6.2089×`.

Estimated mean latency на experiment case mix:

- current baseline: `7403.5 ms`;
- uncertainty-adaptive candidate: `10078.25 ms`;
- all FAST: `2054 ms`;
- all DEEP: `12753 ms`.

Verdicts:

- current bounded baseline: **Accepted**;
- naive uncertainty-only adaptive escalation: **Rejected**;
- доказанная дополнительная ценность DEEP как модели: **Inconclusive**.

Вывод: DEEP остаётся допустимой ролью для явного conflict reasoning, но одна высокая uncertainty не является достаточным основанием платить ~6.2× latency без отдельного quality gain.

### EXP-009 — Bounded Internal State Choice effect

На одном и том же candidate set baseline при `uncertainty=0.0` выбрал `CONTINUE` (`0.62` против `0.58`). После единственного изменения `uncertainty → 1.0`:

- `INSPECT` получил `+0.20` information-gain modifier и итог `0.78`;
- `CONTINUE` получил `−0.20` irreversible-risk modifier и итог `0.42`;
- выбор изменился на `INSPECT`;
- повторный вызов снова выбрал `INSPECT`;
- все modifier contributions остались внутри собственных configured bounds.

Verdict: **Accepted**.

Вывод: Internal State действительно способен причинно и воспроизводимо менять Choice, оставаясь bounded modifier layer, а не владельцем decision authority.

## Метрики

Stage 6.7 сохраняет отдельные verdicts, а не один общий PASS:

- EXP-004 mechanism: Accepted;
- EXP-004 real model quality: Inconclusive;
- EXP-005 production baseline: Accepted;
- EXP-005 naive uncertainty-adaptive routing: Rejected;
- EXP-005 extra DEEP value on current evidence: Inconclusive;
- EXP-009 bounded state effect: Accepted.

Production feature toggles после эксперимента: `request_more_context=false`, `adaptive_routing=false`, `choice_rules_modified=false`.

## Доказано

- system-mediated дополнительный retrieval можно ограничить одним запросом и budget caps без прямого Memory ownership модели;
- текущая conservative routing policy воспроизводима и дешевле uncertainty-only escalation на имеющемся evidence;
- Internal State modifiers оказывают измеримое, bounded и deterministic влияние на Choice.

## Не доказано

- что `REQUEST_CONTEXT` улучшает реальные ответы Qwen3-0.6B, SmolLM3-3B или другой модели;
- что DEEP систематически превосходит FAST на conflict reasoning;
- что текущий routing оптимален на representative workload;
- что coefficients Internal State оптимально откалиброваны;
- что experiment findings должны автоматически менять production policy.

## Итог

Stage 6.7 experimental harness дал полезные дифференцированные результаты. `request_more_context` остаётся выключенным до model-backed quality experiment; naive uncertainty-only DEEP escalation отвергнута; текущий bounded routing baseline сохраняется; bounded Internal State effect подтверждён. Полный regression Stage 6 должен остаться зелёным перед переходом к 6.8 final end-to-end acceptance.
