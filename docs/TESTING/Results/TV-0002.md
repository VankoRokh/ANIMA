# D1 Runtime / Tests / Observability validation

## Цель

Подтвердить воспроизводимость CLI/headless, наблюдаемость и изолированную проверку
[D1](../../ROADMAP/README.md#d1).

## Условия

Исходный прогон: Linux, Python 3.14.4, pytest 9.1.1, временные независимые
экземпляры CLI/headless. Точный commit исходного прогона не записан.
Описание перенесено из [сохранённой записи](https://github.com/VankoRokh/ANIMA/blob/0d535372f644316dcc9bab3c4ac9fbc20e559e05/docs/07_EXPERIMENTS/Test_Results.md);
это ссылка на документ, а не утверждение о проверенном тогда snapshot.

## Сценарий и входные данные

ScenarioRunner и CLI независимо выполняют wake → user_input с текстом `D1 validation`
→ sleep. Сравниваются статус, session, счётчики, последовательность событий и
выбранная память; сохраняются trace/metrics; выполняются regression suite и Check.
Повторение: `.venv/bin/python -m pytest -v -s tests/test_d1_validation.py`.

## Ожидаемый результат

Эквивалентное смысловое состояние, полный наблюдаемый цикл и отсутствие записи
в рабочий data.

## Фактический результат

`49 passed in 0.19s`, project checks без ошибок; оба экземпляра: sleeping,
session=1, 3 события wake/user_input/sleep и одно воспоминание `D1 validation`.

```text
runtime: wake requested
event: wake processed, memory=skipped
runtime: user_input received
event: user_input processed, memory=stored
runtime: sleep requested
event: sleep processed, memory=skipped
runtime: sleeping
```

## Метрики

| Метрика исходного прогона | Значение |
|---|---|
| runtime.wake | ~0.00031 s |
| runtime.user_input | ~0.00019 s |
| runtime.sleep | ~0.00023 s |
| CPU user | ~0.171 s |
| CPU system | ~0.025 s |
| peak RSS | 38812 KB (обозначение исходного отчёта) |

Эти значения показывают работоспособность измерений в одном запуске;
они не являются performance benchmark baseline.

## Доказано

Runtime отделён от CLI; headless воспроизводим; интерфейсы эквивалентны по
проверенным полям; Foundation защищён regression suite; доступны snapshot,
trace и базовые metrics. Исходник проверки:
[test_d1_validation](../../../tests/test_d1_validation.py).

## Не доказано

Долговременная производительность, переносимость resource metrics, конкурентные
экземпляры, необходимость GUI/TUI и поведение будущих когнитивных компонентов.
