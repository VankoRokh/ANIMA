# Stage 4.4 Sandbox Executor / Idempotency

## Цель

Подтвердить первую реальную execution boundary Stage 4: зарегистрированные файловые Tools должны выполняться только внутри sandbox root, side effect должен иметь заранее сохранённую `AgentOperation`, timeout/crash не должны терять recovery obligation, а keyed write должен восстанавливаться без повторного логического эффекта.

## Условия

Проверка выполнена владельцем проекта после получения snapshot `7f944b6a5644614fca49f012ec0331f77c98b2a0`. На snapshot присутствуют `SandboxExecutor`, baseline `fs.list/fs.read/fs.write`, отдельный worker-process execution boundary, atomic write и targeted suites `tests/test_agent_executor.py` и `tests/test_agent_executor_ipc.py`.

## Сценарий и входные данные

Выполнены:

```bash
.venv/bin/python -m pytest -vv tests/test_agent_executor.py tests/test_agent_executor_ipc.py
.venv/bin/python -m pytest -q
bash scripts/check.sh
```

Targeted scenarios покрывают registry/action/operation binding, read/list/write, absolute/parent/symlink path escape, missing files и другие ожидаемые Tool errors, output validation, worker timeout, большой IPC result, confirmed keyed replay, `executing → uncertain` recovery и reconciliation уже применённого либо безопасно повторяемого exact write.

## Ожидаемый результат

Executor исполняет только зарегистрированный trusted handler с валидным Action и заранее persisted AgentOperation; sandbox path не выходит за root; read-only операции не создают side effects; write выполняется атомарно; timeout/system ambiguity write оставляет operation `uncertain`; confirmed keyed write не применяется второй раз; uncertain keyed write сначала reconciles фактическое состояние; полный regression suite предыдущих стадий остаётся работоспособным.

## Фактический результат

Владелец проекта подтвердил успешное прохождение targeted Executor/IPC suites, полного regression suite и `scripts/check.sh` на указанном snapshot. Ошибок Stage 4.4 после локальной проверки не обнаружено.

## Метрики

Отдельный performance baseline на 4.4 не выполнялся. Функциональные проверки Executor/IPC — Passed; полный regression suite — Passed; `scripts/check.sh` — Passed. Общая стоимость Agent orchestration будет измеряться на Stage 4.14.

## Доказано

ANIMA имеет рабочую sandbox execution boundary для bounded filesystem `list/read/write`; intent фиксируется через `AgentOperation` до side effect; unknown/mismatched binding отклоняется; path traversal/absolute path и write-through-symlink блокируются; timeout действительно ограничивает worker process; atomic keyed write имеет deterministic reconciliation/replay semantics; неоднозначный side effect не маскируется как обычный failure.

## Не доказано

4.4 не доказывает Planner, Candidate/Choice integration, Goal verification, полный Agent loop, Event/Memory experience capture или universal recovery для произвольного `idempotency=none` внешнего сервиса. Эти свойства относятся к следующим шагам Stage 4.
