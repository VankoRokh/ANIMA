# Stage 3.2 Source / WorkItem Contract

## Цель

Подтвердить общий контракт `SourceRef`/`WorkItem` для Event, Memory, Knowledge и будущего Asset без копирования тяжёлого payload в Sleep storage.

## Условия

Проверенный snapshot: `51d8947d33f0c1c4e873e0a99c50335f7e7d1169`. Проверка выполнена владельцем проекта в локальном checkout после получения реализации Stage 3.2.

## Сценарий и входные данные

```bash
.venv/bin/python -m pytest -q tests/test_sleep_storage.py tests/test_sleep_contracts.py
.venv/bin/python -m pytest -q
bash scripts/check.sh
```

Контрольный набор создаёт реальные Event/Memory/Knowledge, synthetic Asset reference и отдельный `sleep.db`, проверяет supported/unsupported kinds, dangling source, metadata WorkItem, schema migration v1→v2 и отсутствие большого payload в БД.

## Ожидаемый результат

- Event/Memory/Knowledge/Asset используют один `SourceRef` contract;
- WorkItem хранит source kind/id, work kind, processor/version, priority, cost hint, status и checkpoint reference;
- dangling/unsupported source дают явную ошибку;
- тяжёлый source payload не встраивается в `sleep.db`;
- reopen/migration не повреждают Stage 3.1 storage;
- полная регрессия и project check остаются зелёными.

## Фактический результат

Все запрошенные проверки прошли успешно. Combined targeted suite Stage 3.1+3.2 содержит 32 test cases и завершился без ошибок. Полный `pytest -q` и `scripts/check.sh` также завершились успешно; точное число тестов полного regression suite отдельно не фиксировалось.

## Доказано

`SourceRef` задаёт единый typed reference с stable public ID, `SourceRegistry` проверяет существование источника без владения payload, а `WorkItem` сохраняет только orchestration metadata. `sleep.db` schema v2 сохраняет такие WorkItems и мигрирует существующий v1 storage без разрушения SleepJob.

## Не доказано

Stage 3.2 не доказывает scheduling, processor execution, содержательную консолидацию, реальный checkpoint/resume, derived-result provenance или cross-store recovery. Эти свойства проверяются следующими шагами Stage 3.
