# Stage 4.8 Agent Loop / Runtime Integration

## Цель

Подтвердить первый полный headless Agent loop, который связывает существующий Goal, PlannerAdapter, системную Candidate adaptation, Stage 2 Choice, Action/AgentOperation, SandboxExecutor, factual Observation, deterministic verification и Goal Progress без обхода принятых authority boundaries.

## Условия

Проверка выполнена владельцем проекта после получения изменений из `main` на snapshot `4e09fd8a481a8604a2ba0ef1d0e9c9bf5d41751b`. Использован deterministic Planner и файловый sandbox Stage 4; LLM, durable replay structured artifacts и agent experience capture в эту проверку не входят.

## Сценарий и входные данные

Выполнены targeted `tests/test_agent_loop.py`, полный regression suite и `scripts/check.sh`. Canonical scenario проходит ошибочное чтение отсутствующего файла, replanning, запись `result.txt`, отдельный readback и только после factual content Observation — успешное завершение Goal. Дополнительно проверяются `cannot_progress`, verified blocker, max-steps guard, передача предыдущих Observation следующему turn и правило одного Action на turn.

## Ожидаемый результат

Обычный turn проходит lifecycle `planning → planned → selected → executing → executed → observed → verified → completed`; AgentOperation фиксируется до side effect; обычная Tool failure остаётся Receipt/Observation, а не техническим Step failure; успешный write сам по себе не завершает Goal; verified readback завершает Goal и Run.

## Фактический результат

Владелец проекта подтвердил успешное прохождение targeted Agent loop suite, полного regression suite и `scripts/check.sh` на указанном snapshot. Ошибок Stage 4.8 не обнаружено.
