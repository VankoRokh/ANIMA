## Поведение

- Новый `anima.release_v01` запущен как отдельный постоянный экземпляр, успешно открыт в новом Python-процессе с сохранённой Identity.
- Исходные пользовательские Events и связи с Memory доступны после повторного запуска; `event_index_complete=true`; `source_links=ALL_ACCOUNTED`.
- Контекст ограничен установленным бюджетом, модель не вызывается; это **не** подтверждение качества текстового ответа или универсального semantic retrieval.
- Отдельный опциональный sandbox выполнил одно разрешённое действие с `sandbox_goal_status=completed` и `sandbox_effects=1`; это не реальное физическое действие.
- Выполнение позитивных и отрицательных subprocess-тестов включало отдельное убийство процесса `SIGKILL` после подтверждённой записи. Не проверялись произвольный fault cut, отключение питания или повреждение базы данных.

**Ограничения интерпретации:** нагрузка состоит из повторяемых синтетических фраз. Одна Memory на 128 событий не означает, что эпизодическая группировка корректна для разных тем/сессий. Индекс и исходный журнал сохраняют доступ к источникам, но не доказывают отсутствие ложных ассоциаций. `performance_status=MEASURED_NOT_SLO_GATED`: пороги производительности не утверждены до измерения, поэтому релизного performance PASS нет. Нельзя экстраполировать ресурсный baseline до 10⁵ событий, многосуточной нагрузки и нестандартных входов.

## Решение

Эта проверка закрывает **локальный функциональный gate** ровно указанного commit. Перед маркировкой `v0.1` требуется итоговый точный SHA, соответствующая полная регрессия, проверка границ версии, документирование остаточных рисков и принятие релизного контракта. Raspberry Pi не входит в обязательный gate.
