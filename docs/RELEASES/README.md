# Релизы ANIMA

**Канонические требования и приёмка находятся в [разделе версий](../versions/README.md).** Эта страница сохраняет прежние ссылки на исходные отчёты и релизный контракт. Исторические Stage и их статусы остаются в [`project.json`](../project.json); они **не определяют готовность конкретной версии ANIMA**. Отдельная лаборатория или эксперимент, даже с PASS, не становится частью релиза автоматически.

## Последний допущенный кандидат — ANIMA v0.2 RC1

- [Контракт v0.2 RC1](../versions/v0.2/contract.md) — проверенные Memory/Knowledge/Context инварианты и доверенные границы.
- [Карточка независимой приёмки H5.8](../versions/v0.2/acceptance.md) — 2315 PASS, H57-01–03 FIXED_VERIFIED, APPROVE_RC на точном SHA.
- [Заметки RC1](../versions/v0.2/release-notes.md) — функциональность, O58-01/O58-02, ограничения и порядок публикации `v0.2.0-rc.1`.

**Статус:** владелец допустил код `1364e62634669ef553df0b2f2d7a1159d404383f` к RC 19 ноября 2026 года. Аннотированный тег `v0.2.0-rc.1` опубликован и проверен; GitHub prerelease пока ожидается. Версия **не** объявлена stable.

Публикация Git tag и GitHub Release отслеживается отдельно от решения о приёмке; не считать тег существующим без подтверждения в Git. Запуск — в [эксплуатации](../operations.md).

## После RC1

Следующий функциональный контракт не принят: направления будущих релизов остаются идеями без назначенных обязательных функций, сроков и номеров. Направления: развитие FAST/DEEP/SLEEP, новые интерфейсы восприятия, переработка памяти, метапамять, аппаратный перенос. Подробная дорожная карта составляется только после начала работы над следующим выбранным релизом.
