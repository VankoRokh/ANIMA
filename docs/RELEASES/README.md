# Релизы ANIMA

**Канонические требования и приёмка находятся в [разделе версий](../versions/README.md).** Эта страница сохраняет прежние ссылки на исходные отчёты и релизный контракт. Исторические Stage и их статусы остаются в [`project.json`](../project.json); они **не определяют готовность конкретной версии ANIMA**. Отдельная лаборатория или эксперимент, даже с PASS, не становится частью релиза автоматически.

## Активная версия — ANIMA v0.1

- [Канонический контракт v0.1](../versions/v0.1/contract.md) — границы, обязательные функции и R-01–R-10; [прежний адрес контракта](ANIMA_v0_1_Release_Contract.md) сохранён для совместимости.
- [Актуальная карточка приёмки](../versions/v0.1/acceptance.md) — состояние требований на конкретных SHA и отдельное решение владельца.
- [Аудит готовности](ANIMA_v0_1_Gap_Audit.md) — известные риски, нерешённые требования, отношение к экспериментам.
- [Локальная приёмка на ноутбуке](ANIMA_v0_1_Notebook_Evidence.md) — измерения владельца для конкретного исходного commit.

**Статус:** кандидат; финальный тег и подтверждение приёмки версии ещё не выпущены. Запуск текущего кандидата описан в [эксплуатации](../OPERATIONS/README.md).

## Будущие версии

Будущие релизы сейчас — **только идеи**, без жёсткой привязки к номерам, срокам, Stage и обязательным действиям. Направления: развитие FAST/DEEP/SLEEP, новые интерфейсы восприятия, переработка памяти, метапамять, аппаратный перенос. Подробная дорожная карта составляется только после начала работы над следующим выбранным релизом.
