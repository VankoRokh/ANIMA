# Восстановление

## Потерян или заменён компьютер

1. Установить базовые инструменты и получить код в новую папку по Setup.
2. Найти отдельную резервную копию data и её commit/Python metadata.
3. Проверить сумму и состав архива.
4. Выбрать соответствующий commit кода.
5. Восстановить данные до первого реального запуска.
6. Проверить состояние/историю, затем запустить и подтвердить продолжение.

Если резервной копии данных нет, Git восстанавливает проект, но не прежний опыт.

## Команды для отдельной папки восстановления

Ниже путь архива нужно заменить реальным абсолютным путём. Папка ANIMA-restored должна быть новой:

```bash
git clone https://github.com/VankoRokh/ANIMA.git ANIMA-restored
cd ANIMA-restored
task_backup_file="/absolute/path/ANIMA-YYYYMMDD-HHMMSS.tar.gz"
task_commit="$(cat "$task_backup_file.commit")"
git checkout --detach "$task_commit"
tar -tzf "$task_backup_file"
```

Проверить, что содержимое — ожидаемый data/ и нет посторонних путей. В новой папке, где data ещё отсутствует:

```bash
tar -xzf "$task_backup_file"
bash scripts/setup.sh
bash scripts/check.sh
```

Проверить JSON/JSONL и счётчик session до run. Сравнить с исходной копией; запуск увеличит сессию и добавит события. Затем:

```bash
bash scripts/run.sh
```

Если восстановлен commit до появления scripts, следовать его доступному окружению и запускать python3 main.py из корня; перенос и обновление схемы не выполнять автоматически.

Эта процедура не перезаписывает действующий экземпляр. Повреждённый исходный data сохраняется для анализа. Резервная копия остаётся независимой.

## Потеряна локальная документация

Сделать свежий clone в новую папку и сравнить с повреждённой. Сохранять незакоммиченные заметки до любых восстанавливающих операций. Восстановление Git не охватывает изменения, которые не были отправлены или сохранены отдельно.

## Потерян контекст помощника

Передать [AI_CONTEXT](../00_HOME/AI_CONTEXT.md) и связанные страницы. Проверить Project_Status, текущий этап и последние commit. Источники — принятые ADR, описание и фактический код.

## Несовместимы данные и код

Вернуться к commit из metadata в отдельной папке. Прямой перезапуск на произвольной новой версии не является миграцией. Дальнейшее обновление требует отдельного плана и резервной копии.

## Что уже проверяется автоматически

Check создаёт синтетический экземпляр, архивирует data, восстанавливает в другую временную установку и продолжает сессию. Пользовательский data не затрагивается. Полный перенос реального экземпляра остаётся отдельной проверкой Stage 0.
