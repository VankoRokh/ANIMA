# Развёртывание

Целевая начальная среда: Linux, Bash, Git, Python и venv. Текущий прототип не требует внешних Python-пакетов, моделей, API-ключей или отдельного сервиса.

**Проверенная среда:** Python 3.12.14. Setup допускает Python 3.12 и новее; другие версии должны пройти Check. Исторический Python 3.14.4 на ноутбуке владельца здесь заново не проверялся.

## Новая установка

На Ubuntu при отсутствии базовых инструментов:

```bash
sudo apt update
sudo apt install git python3 python3-venv
```

Затем в выбранной рабочей папке:

```bash
git clone https://github.com/VankoRokh/ANIMA.git
cd ANIMA
python3 --version
bash scripts/setup.sh
bash scripts/check.sh
```

setup.sh создаёт .venv, если её нет, проверяет версию существующего интерпретатора и не устанавливает внешние пакеты. Непригодную существующую среду не удаляет.

Для выбора другого установленного Python:

```bash
ANIMA_PYTHON=python3.14 bash scripts/setup.sh
```

Если venv для этого интерпретатора недоступна, установить соответствующий системный пакет. Не переносить .venv с другого компьютера: окружение создаётся заново. [Python venv](https://docs.python.org/3/library/venv.html).

## Что проверяет Check

- Наличие входных страниц, ссылки и разделы реестра.
- Согласованность ID и статусов модулей.
- Синтаксис исходного Python и JSON-конфигурации VS Code.
- Две сессии изолированного экземпляра: непустой и пустой ввод.
- Резервирование/восстановление временного data с продолжением сессии.
- Сохранение истории и отсутствие реальных данных в отслеживаемых файлах.

Check не изменяет реальный data. Это проверка базового сценария; она не покрывает все ошибки питания, повреждения и параллельной записи.

## Первый запуск

Для нового экземпляра:

```bash
bash scripts/run.sh
```

Введите одну строку, затем Enter для штатного сна. Запуск создаст локальный data. Для продолжения старого экземпляра сначала восстановить его данные по [Recovery](Recovery.md).

run.sh выбирает .venv/bin/python, а при её отсутствии python3, и запускает из корня репозитория. ANIMA_PYTHON позволяет явно выбрать интерпретатор. Внешний путь к данным пока не поддерживается.

## Обновление и проверка редакторов

Существующую папку не клонировать поверх. Проверить изменения и получить обновление по [Development](Development.md). Данные резервировать отдельно по [Backup](Backup.md).
