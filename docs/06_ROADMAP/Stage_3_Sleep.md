# Stage 3 — Sleep

**Рабочий статус: Planned.** Состав этапа: Draft.

## Цель

Добавить ограниченную по ресурсам и прерываемую обработку опыта; проверить роли Fast/Deep.

## Условия старта

Stage 1–2; выбран минимальный адаптер глубокой обработки и критерии полезности. Без модели допустим первый детерминированный прототип консолидации.

## Задачи

- [ ] Схемы задания, checkpoint и пробуждения.
- [ ] Первый конвейер Fast/Deep с измерением задержки и RAM.
- [ ] Консолидация фиксированного набора с сохранением источников.
- [ ] Учет противоречий и истории переоценки.
- [ ] Сравнение результатов повторного запуска и прерывания.
- [ ] Отдельный EXP-002 по обновлению Fast; обучение весов не является условием базового сна.

## Критерии завершения

Фоновое задание прерывается и продолжается, не теряет данные и укладывается в заданный бюджет. Повторная обработка не размножает выводы неконтролируемо; отчёт имеет происхождение.

## Результат и пределы

Рабочая консолидация. Не обещаем автоматическое обучение Fast или заранее фиксированный суточный режим.

## История завершения

Этап не начат. После закрытия сохранить дату, commit, результаты измерений, уроки и оставшийся технический долг.
