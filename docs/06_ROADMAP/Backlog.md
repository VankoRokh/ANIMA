# Очередь работы

Это конкретные задачи текущей основы и список вопросов будущих этапов. Статус задач не заменяет статусы модулей.

## Ближайшие задачи

| ID | Задача | Готово, когда | Статус |
|---|---|---|---|
| D0-05 | VS Code и Obsidian на ноутбуке | Check проходит; карта и реестр открывают нужные страницы | Done: подтверждено владельцем 2026-10-12 |
| D0-06 | Пробное резервирование и восстановление | Временный экземпляр восстановлен из архива в другую установку, история и продолжение сессии проверены | Done: Python 3.12.14 |
| D0-07 | Сохранение в GitHub через локальный Git | Commit e155c69 опубликован; файлы и чтение через GitHub проверены | Done: 2026-10-12 |
| SW-01 | Чтение выбранной памяти и корректный CLI | memories.jsonl читается по source/content; сырой журнал отображается отдельно; пустой ввод не увеличивает выбранную память | Pending |
| SW-02 | Уникальная идентичность | ID сохраняется после перезапуска/переноса; новый экземпляр отличается | Pending |
| SW-03 | Надёжная запись состояния | Атомарная запись и понятная обработка повреждённого/несовместимого файла проверены | Pending |
| SW-04 | Валидация событий и журналов | Неверные типы и повреждённые строки дают определённый результат | Pending |
| SW-05 | Завершение и прерывание | Ctrl+C/EOF имеют определённое поведение без молчаливой потери состояния | Pending |
| SW-06 | Расположение данных | Путь задаётся явно, миграция имеющегося data проверена | Pending |
| SW-07 | Выделение CLI | Интерфейс переносится из main.py с сохранением наблюдаемого поведения | Pending |

Не объединять все SW в один commit: каждая задача должна иметь понятный результат и проверку. Для каждого изменения обновлять [Project Status](../00_HOME/Project_Status.md) и описание затронутого модуля.

## Вопросы до следующих этапов

| Направление | Что определить |
|---|---|
| Память | IDs, источники, запросы и метрики релевантности |
| Важность | Контрольный набор, baseline и ограничение объёма |
| Эмоции | Минимальные переменные, шкалы и критерии полезности |
| Цели | Приоритет, отмена, наблюдаемый результат |
| Fast / Deep | Первые модели/адаптеры, задержка, память и режим offline |
| Сон | Прерывание, checkpoints, история вывода |
| Железо | Бюджет нагрузки до выбора плат/ускорителей |
| Публичный проект | Лицензия исходников и условия использования моделей |
| Резервирование | Место, периодичность и практический тест восстановления |
