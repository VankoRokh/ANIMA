## Критерии завершения

Владелец находит любой компонент через реестр; ссылки доступны в GitHub и редакторе. Проверка проходит после получения репозитория. Новый помощник восстанавливает контекст через AI_CONTEXT. Восстановление из резервной копии проверено на временном экземпляре, а реальная процедура резервирования назначена явно.

## Результат и ограничения

В рабочей среде прошли Setup и Check на Python 3.12.14: 48 страниц, 282 внутренние ссылки, 32 карточки модулей; архив восстановлен во вторую временную установку и сессия продолжена. Независимая резервная копия реального экземпляра ещё не настроена.

Подготовка документации не реализует модели, идентичность или когнитивный сон. Полный перенос работающего экземпляра и устойчивость к сбоям остаются критериями Stage 0.
