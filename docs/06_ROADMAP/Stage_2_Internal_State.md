# Stage 2 — Internal State

## Goal

Ввести минимальные цели и внутренние регулирующие переменные, влияние которых на выбор можно причинно проследить.

## Observable result

Одинаковая внешняя ситуация при разных контролируемых внутренних состояниях приводит к заранее ожидаемому различию в приоритетах/выборе, а система может показать причину изменения.

## Required work

- [ ] Формат цели: источник, приоритет, статус, критерий результата, отмена.
- [ ] Малый набор bounded internal variables.
- [ ] Явные правила изменения и decay/recovery, где нужны.
- [ ] Trace влияния состояния на внимание/выбор.
- [ ] Сохранение и восстановление внутренних переменных.
- [ ] Внешнее эмоциональное выражение как зависимый слой, а не источник внутренних оценок.

## Test scenarios

1. Neutral baseline и несколько заранее заданных внутренних состояний на одинаковом наборе входов.
2. Значения никогда не выходят за допустимые диапазоны.
3. Каждое изменение имеет source/reason в trace.
4. Restart сохраняет состояние без скрытого дрейфа.
5. Завершённая/отменённая цель переходит в определённое состояние и не продолжает влиять как активная.
6. Внешнее выражение не изменяет внутренний слой обратным эффектом без отдельного правила.

## Acceptance criteria

Все контрольные сценарии дают предсказуемое направление изменения выбора и объяснимую причинную цепочку. Состояние воспроизводится после restart.

## Evidence to save

Сравнение neutral/altered state на одном scenario set и trace причин каждого изменения.
