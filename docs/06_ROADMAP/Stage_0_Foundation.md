# Stage 0 — Foundation

**Рабочий статус: In Progress.** Существующий прототип: 00.1-alpha.

## Цель

Получить однозначный и восстанавливаемый базовый цикл экземпляра, на который можно опираться при развитии памяти и моделей.

## Условия старта

D0, Python-окружение, сохранённый исходный код. Проверка базового цикла выполняется через scripts/check.sh.

## Задачи

- [x] Очередь событий и сырой журнал.
- [x] Сохранение состояния и счётчика сессий.
- [x] Фильтр непустого ввода и отдельная запись выбранной памяти.
- [x] Базовый CLI и штатный переход sleeping.
- [x] SW-01: чтение и отображение выбранной памяти.
- [x] SW-02: минимальная идентичность и версия схемы.
- [ ] SW-03 / SW-04: защита состояния и проверка данных.
- [ ] SW-05: обработка штатного прерывания.
- [ ] SW-06: явная конфигурация расположения данных.
- [ ] Проверка резервирования, восстановления и миграции текущих файлов.

## Критерии завершения

Две сессии сохраняют ID, историю и счётчики. Сырой журнал и выбранная память отображаются отдельно и правильно. Известные неверные данные дают понятную ошибку. Копия переносится в новую установку и проходит проверку без потери исходных файлов.

## Результат

Надёжная основа хранения и жизненного цикла. Когнитивные функции ещё не требуются.

## История

Этап не завершён. Реализованные части привязаны к [аудиту исходных commit](../03_SOFTWARE/Repository_Audit.md). При закрытии записать дату, commit, проверки и оставшийся долг.
