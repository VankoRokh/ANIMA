# Stage 4 — Agent

**Рабочий статус: Planned.** Состав этапа: Draft.

## Цель

Превратить задачу в план действий с проверяемым результатом.

## Условия старта

Stage 1–3; известны память, цели, ограничения и минимальный контур обработки.

## Задачи

- [ ] Один адаптер инструмента с явными аргументами.
- [ ] Простой план и наблюдаемый результат каждого шага.
- [ ] Обработка ошибки и отмена/восстановление обратимого действия.
- [ ] Сохранение наблюдений об исполнении.
- [ ] Контроль повторной команды и незавершённой задачи.
- [ ] Проверка сценария отказа инструмента.

## Критерии завершения

Одна законченная задача выполняется в тестовой среде; результат подтверждён наблюдением, ошибка обнаружена, состояние после прерывания определено.

## Результат и пределы

Первый действующий агент. Общая автономность и произвольные задачи не объявляются готовыми по одному демонстрационному сценарию.

## История завершения

Этап не начат. После закрытия сохранить дату, commit, результаты измерений, уроки и оставшийся технический долг.
