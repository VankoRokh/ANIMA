# Stage 1 — Cognitive Memory

**Рабочий статус: Planned.** Состав этапа: Draft.

## Цель

Создать долговременную память, которую можно извлекать по текущей задаче и проверять по исходным событиям.

## Условия старта

Stage 0: однозначные журналы, идентичность, восстановление и версия данных.

## Задачи

- [ ] Схема эпизодов с IDs и ссылкой на исходное событие.
- [ ] Ограниченный рабочий контекст.
- [ ] Простой тематический поиск и контрольные примеры.
- [ ] Метаданные и базовая оценка важности; эмоциональное усиление исследуется отдельно.
- [ ] Первое семантическое обобщение с источниками.
- [ ] Правила архива/сжатия; удаление требует проверенного восстановления.

## Критерии завершения

На контрольном наборе ANIMA записывает и извлекает релевантные эпизоды, отличает вывод от исходного события, соблюдает лимит контекста и сохраняет историю после восстановления.

## Результат и пределы

Рабочая долговременная память. Полезность ранжирования подтверждается измерением, а не названием importance_score.

## История завершения

Этап не начат. После закрытия сохранить дату, commit, результаты измерений, уроки и оставшийся технический долг.
