# Stage 1 — Cognitive Memory

## Goal

Создать долговременную память, которая надёжно связывает извлечённый опыт с исходными событиями и формирует ограниченный рабочий контекст.

## Observable result

На фиксированном корпусе событий ANIMA по запросу возвращает ожидаемые эпизоды, показывает их происхождение и не переполняет заданный бюджет контекста.

## Conditions

Stage 0 + D1. Test harness и provenance должны быть доступны до усложнения схемы памяти.

## Required work

- [ ] Стабильные IDs событий и эпизодов.
- [ ] Явные ссылки эпизода на source event(s).
- [ ] Ограниченный working context с измеримым бюджетом.
- [ ] Детерминированный baseline retrieval до embeddings/LLM.
- [ ] Простые metadata/importance rules как baseline.
- [ ] Обработка дубликатов и противоречивых записей без потери источников.
- [ ] Правила архива/сжатия только после доказанного восстановления.

Семантическое обобщение генеративной моделью **не является условием Stage 1**. Оно вводится позднее как сравниваемый механизм, когда появятся baseline и benchmark.

## Test scenarios

1. Синтетический корпус не менее чем из нескольких десятков событий с заранее известными связями и запросами.
2. Для каждого контрольного запроса ожидаемые IDs находятся в заданном top-k.
3. Каждый извлечённый эпизод возвращает существующий source и не подменяет вывод исходным фактом.
4. Context budget никогда не превышается даже при большом числе релевантных записей.
5. Restart/recovery сохраняет IDs и результат выборки.
6. Повреждённая/несовместимая запись даёт определённую ошибку.
7. Regression D1/Stage 0 проходит без изменений.

## Acceptance criteria

- 100% контрольных запросов на детерминированном test corpus возвращают обязательные expected IDs в заданном top-k;
- 100% возвращённых записей имеют валидное provenance;
- context budget соблюдается во всех контрольных сценариях;
- результат воспроизводим после restart/recovery.

## Evidence to save

Benchmark корпуса, таблица query → expected/retrieved IDs, максимальный размер контекста и финальный regression result.
