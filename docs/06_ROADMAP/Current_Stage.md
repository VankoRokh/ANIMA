## Последняя завершённая задача: SW-04

ANIMA получила явный контракт событий и JSONL-хранилищ.

`Event` принимает только `wake`, `user_input` и `sleep` с допустимыми для каждого типа payload. Сохранённая запись события дополнительно проверяется по полям `type`, `payload` и `timestamp`.

`EventLog` проверяет события перед записью и умеет читать `events.jsonl` с валидацией каждой непустой строки. Повреждённый JSON и структурно несовместимая запись дают понятную ошибку с номером строки.

`MemoryStore` проверяет выбранную память по полям `source`, `timestamp` и `content.text` до записи. `EpisodicMemory` использует тот же контракт при чтении и сообщает номер повреждённой строки.

Проверено:

1. Допустимые события создаются, неизвестные типы и неверные payload отклоняются.
2. Валидный журнал событий читается в исходном порядке.
3. Повреждённый и несовместимый `events.jsonl` дают определённую ошибку с номером строки.
4. Некорректная память не изменяет `memories.jsonl`.
5. Повреждённый и несовместимый `memories.jsonl` дают определённую ошибку с номером строки.
6. Полная проверка проекта и recovery проходят на Python 3.14.4.

Реализация и проверки опубликованы в commit `d67f998`.

## Ближайшая задача: SW-05

Корректное завершение и прерывание процесса.

Цель — определить поведение ANIMA при `Ctrl+C` и EOF так, чтобы прерывание не приводило к молчаливой потере состояния и оставляло понятный результат для следующего запуска.

Перед изменением проверить `main.py`, жизненный цикл `wake` / `sleep`, состояние сессии и существующие процедуры восстановления.
