# Текущий этап

## Сейчас: Stage 0 — Foundation

D0 завершён 2026-10-12. Система документации опубликована в e155c69; локальная проверка VS Code/Obsidian подтверждена владельцем, доступ к актуальным страницам через GitHub проверен. Сам прототип остаётся 00.1-alpha.

## Последняя завершённая задача: SW-02

ANIMA получила минимальную постоянную идентичность экземпляра.

`Identity` создаёт UUID4 `instance_id` только для нового экземпляра и хранит его в `data/identity.json` вместе с `schema_version: 1` и временем создания. При повторном запуске существующий ID загружается из файла.

CLI показывает текущий `Instance ID`.

Проверено:

1. После перезапуска ID остаётся прежним.
2. После переноса identity.json ID сохраняется.
3. Новый экземпляр без старой идентичности получает другой ID.

Реализация опубликована в commit `e895dac` (`feat(identity): add persistent instance identity`).

## Ближайшая задача: SW-03

Надёжная запись состояния.

Цель — снизить риск повреждения `data/state.json`: перейти к более безопасной записи и определить явное поведение при повреждённом или несовместимом состоянии.

Перед изменением проверить текущий `state.py`, формат `state.json`, процедуры восстановления и связанные архитектурные страницы.

## После SW-03

Валидация событий и журналов, восстановление после прерывания и явное расположение данных. Детали: [Stage 0](Stage_0_Foundation.md), [Backlog](Backlog.md).

Более сложные механизмы происхождения и конфликтов копий идентичности пока не входят в SW-03.
