# Текущий этап

## Сейчас: D0 — документация и восстановление

Цель — закрепить знания в репозитории и дать владельцу понятный рабочий вход через VS Code/Obsidian.

Подготовлены карта, реестр из 32 компонентов, описания, исходный аудит, ADR, планы этапов, правила работы, восстановление и вспомогательные команды. Сам прототип остаётся 00.1-alpha.

## Следующее действие владельца

Локальные проверки и навигация в VS Code/Obsidian подтверждены владельцем 2026-10-12. Следующий шаг — публикация проверенного документационного этапа:

1. Проверить текущую ветку и состав изменений в Source Control.
2. Добавить в commit только документацию, scripts, настройки VS Code, README и .gitignore.
3. Просмотреть подготовленные изменения и создать документационный commit.
4. Выполнить push, проверить доступность документов на GitHub и закрыть D0.

Подробные команды и действия: [Development](../09_OPERATIONS/Development.md). Прямую запись через подключение помощника GitHub отклонил с 403; отправку выполняет локальный Git владельца.

## Критерий завершения D0

На рабочем компьютере проходит Check, ссылки открывают нужные описания, понятно состояние каждого модуля и ближайшая задача. У нового помощника достаточно AI_CONTEXT и связанных страниц, чтобы продолжить работу.

## После D0: продолжение Stage 0

Первое кодовое изменение — SW-01: согласовать чтение выбранной памяти с memories.jsonl и её форматом source/content. Сейчас экран считает и показывает events.jsonl.

Затем уникальная идентичность, надёжность состояния, проверка восстановления и обработка прерывания. Детали: [Stage 0](Stage_0_Foundation.md), [Backlog](Backlog.md).

Оценка важности и эмоциональная консолидация начинаются после того, как хранение и чтение опыта однозначны.
