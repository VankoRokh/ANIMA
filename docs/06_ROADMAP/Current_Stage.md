# Текущий этап

## Сейчас: Stage 0 — Foundation

D0 завершён 2026-10-12. Система документации опубликована в e155c69; локальная проверка VS Code/Obsidian подтверждена владельцем, доступ к актуальным страницам через GitHub проверен. Сам прототип остаётся 00.1-alpha.

## Ближайшая задача: SW-01

Согласовать чтение выбранной памяти с memories.jsonl и его форматом source/content. Сейчас экран считает и показывает events.jsonl, хотя называет эти записи воспоминаниями.

Перед изменением прочитать [Memory](../02_ARCHITECTURE/Memory.md), [Event Pipeline](../03_SOFTWARE/Event_Pipeline.md) и текущий main.py. Команды работы и проверки: [Development](../09_OPERATIONS/Development.md).

## План задачи

1. Уточнить минимальный интерфейс чтения выбранных воспоминаний.
2. Сохранить отдельный доступ к исходному журналу событий.
3. Обновить счётчик и вывод последних выбранных записей в CLI.
4. Проверить непустой ввод, пустой ввод и повторный запуск на временных данных.
5. Обновить описание затронутых модулей, статус и этап в том же изменении.

## Критерий завершения SW-01

После одной непустой строки и служебных событий отображается одно выбранное воспоминание. Пустой ввод не увеличивает их число. Повторный запуск сохраняет и корректно показывает прежние записи. Сырой журнал доступен отдельно.

SW-01 пока не начата. Данные экземпляра и схемы файлов сохраняются; необходимость миграции рассматривается только при изменении формата.

## После SW-01

Уникальная идентичность, надёжность состояния, проверка восстановления и обработка прерывания. Детали: [Stage 0](Stage_0_Foundation.md), [Backlog](Backlog.md).

Оценка важности и эмоциональная консолидация начинаются после того, как хранение и чтение опыта однозначны.
