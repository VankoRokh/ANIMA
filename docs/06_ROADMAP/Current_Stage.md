# Текущий этап

## Переход после Stage 0

D0 завершён 2026-10-12. Stage 0 — Foundation завершён 2026-10-13. Прототип остаётся 00.1-alpha.

## Финальная проверка Stage 0

После SW-06 выполнена отдельная ручная проверка Backup/Recovery на snapshot `8499166`.

Проверено:

1. Внешний экземпляр через `ANIMA_DATA_DIR` провёл две сессии: `session=2`, `status=sleeping`, 6 сырых событий и 2 выбранных воспоминания.
2. Каталог экземпляра архивирован отдельно от кода; архив проверен по SHA-256.
3. Новая установка кода восстановлена на точный commit из metadata.
4. Четыре файла данных восстановлены в новый внешний каталог и совпали с исходными побайтно.
5. Восстановленная копия продолжила работу как `session=3`, сохранила прежний `instance_id`, получила 9 событий и 3 воспоминания.
6. Контрольные суммы исходного каталога после продолжения восстановленной копии не изменились.

Этим выполнены все зафиксированные критерии [Stage 0](Stage_0_Foundation.md).

## Переход к Stage 1

После закрытия Stage 0 выполнен отдельный технический шаг SW-07: терминальный интерфейс вынесен из `main.py` в `anima/interfaces/cli.py` без изменения наблюдаемого поведения. Реализация зафиксирована в commit `8a169f6`; Check отдельно подтверждает границу между сборкой приложения и CLI, а прежние сценарии ввода, прерывания, памяти и восстановления продолжают проходить.

Stage 1 — Cognitive Memory остаётся Planned. Следующая работа — сверить его состав, входные условия и первые задачи до изменения схем памяти.

ID событий, версия схемы журналов, timezone и правила восстановления повреждённой строки остаются отдельными будущими решениями.
