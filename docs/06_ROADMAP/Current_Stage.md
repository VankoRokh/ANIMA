## Последняя завершённая задача: SW-06

ANIMA получила явную конфигурацию расположения данных через `ANIMA_DATA_DIR`.

Без переменной используется `<project>/data`. Абсолютный путь используется напрямую, относительный разрешается от корня проекта, поэтому экземпляр больше не зависит от текущей рабочей директории.

Проверено:

1. Значение по умолчанию указывает на `data` в корне проекта.
2. Относительный `ANIMA_DATA_DIR` разрешается от корня проекта.
3. Пустое значение отклоняется с понятной ошибкой.
4. Один экземпляр продолжается при запуске из разных cwd.
5. Копирование каталога данных сохраняет `instance_id`, состояние, историю событий и выбранную память.
6. Продолжение скопированного экземпляра не изменяет исходный каталог.

Реализация и проверки опубликованы в commit `eb1cc28`.

## Ближайшая задача

Контрольная проверка резервирования, восстановления и миграции текущих файлов с учётом `ANIMA_DATA_DIR`.

Нужно сверить ручные инструкции Backup/Recovery с новым расположением данных, проверить восстановление копии в отдельную установку и убедиться, что процедура не смешивает код проекта с данными конкретного экземпляра.
