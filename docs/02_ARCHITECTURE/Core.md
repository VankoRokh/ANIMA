# Core

Core объединяет состояние экземпляра, идентичность и передачу событий. В текущем прототипе это классы Python, а не отдельный процесс или физическая плата. Основная координация остаётся в main.py.

## CORE-01

**Идентичность.** Решение: **Accepted**. Реализация: **Prototype**.

- **Назначение:** Отличать экземпляры ANIMA и сохранять непрерывность при перезапуске и переносе данных.
- **Входы:** Необязательный путь identity_file; существующий identity.json или его отсутствие.
- **Выходы:** Постоянные instance_id, schema_version и created_at.
- **Зависимости:** uuid, json, pathlib, datetime и локальная файловая система.
- **Код:** [Identity](../../anima/core/identity.py).
- **Сейчас:** Новый экземпляр получает UUID4 и сохраняет его в data/identity.json. Существующий экземпляр загружает прежний ID. CLI показывает Instance ID.
- **Следующее:** Добавить валидацию, безопасную запись и в дальнейшем правила происхождения копий.
- **Проблемы:** Одновременная работа двух скопированных экземпляров с одним ID пока не различается. Повреждённый identity.json вызывает ошибку загрузки.
- **Проверка готовности:** Один ID сохраняется после перезапуска и переноса; новый экземпляр получает другой ID. Проверено в SW-02.

## CORE-02

**Состояние экземпляра.** Решение: **Accepted**. Реализация: **Prototype**.

- **Назначение:** Хранить статус и счётчики между запусками.
- **Входы:** wake(), sleep(), register_event(); необязательный state_file в конструкторе.
- **Выходы:** get() возвращает словарь; save() записывает data/state.json.
- **Зависимости:** json, pathlib, datetime; локальная файловая система.
- **Код:** [AnimaState](../../anima/core/state.py).
- **Сейчас:** Поля name, version, status, session, created_at, last_wake, last_sleep, events_processed. wake увеличивает session; каждое обработанное событие увеличивает общий счётчик.
- **Следующее:** Валидация схемы, атомарная запись, версионирование и корректное восстановление после прерывания.
- **Проблемы:** Повреждённый JSON останавливает загрузку. get() отдаёт изменяемую ссылку. Время локальное, без часового пояса.
- **Проверка готовности:** Две сессии сохраняют счётчик; перенос сохраняет значения; повреждение обрабатывается без тихой потери.
## CORE-03

**События и EventBus.** Решение: **Accepted**. Реализация: **Prototype**.

- **Назначение:** Передавать события между частями текущего процесса.
- **Входы:** emit(event_type, payload=None).
- **Выходы:** Event с event_type, payload, timestamp; FIFO через next_event(), состояние очереди через has_events(). to_dict() выдаёт type, payload, timestamp.
- **Зависимости:** datetime; process_events() в main.py потребляет очередь.
- **Код:** [Event и EventBus](../../anima/core/event_bus.py).
- **Сейчас:** Очередь — список в оперативной памяти. При пустой очереди next_event() возвращает None.
- **Следующее:** Определить схему, обработку ошибок и требования к постоянной/межпроцессной очереди.
- **Проблемы:** Нет event_id, подтверждения доставки, ограничения очереди или синхронизации потоков. Потеря процесса теряет невычитанную очередь.
- **Проверка готовности:** События передаются в исходном порядке, ошибки записи не маскируются; требования доставки задаются отдельно.
