# Начать или вернуться к ANIMA

ANIMA — проект модульного ИИ-агента с сохраняемым опытом и возможностью менять вычислитель и тело. Сейчас работает небольшой Python-прототип регистрации событий. Полное описание: [ANIMA](ANIMA.md).

## Вернуться после перерыва

1. Прочитать [текущее состояние](Project_Status.md): последняя завершённая работа, ближайшая задача, ограничения.
2. Открыть [карту](System_Map.md) и [реестр модулей](Module_Index.md): найти нужную подсистему и её описание.
3. Прочитать [текущий этап](../06_ROADMAP/Current_Stage.md) и [общий план](../06_ROADMAP/Roadmap.md).
4. Проверить [решения ADR](../08_DECISIONS/README.md) и историю Git в Source Control.
5. Выполнить проверку проекта и только затем менять код.

Ориентир — восстановить общий контекст за 15 минут. Детали конкретного модуля читать по необходимости.

## Новый компьютер

Следовать [Setup](../09_OPERATIONS/Setup.md). Для восстановления прежнего экземпляра дополнительно нужен [Recovery](../09_OPERATIONS/Recovery.md): клонирование кода не восстанавливает его личные данные.

В терминале VS Code из корня репозитория:

```bash
bash scripts/setup.sh
bash scripts/check.sh
bash scripts/run.sh
```

Те же действия доступны через **Terminal → Run Task → ANIMA: Setup / Check / Run**.

## Новый ИИ-помощник

Передать инструкцию:

> Прочитай docs/00_HOME/AI_CONTEXT.md, затем связанные страницы статуса, архитектуры и текущего этапа. Сверь описание с кодом. Не считай Draft принятой архитектурой и не меняй данные экземпляра.

[AI_CONTEXT](AI_CONTEXT.md) содержит порядок чтения, а не копию всей документации.
