# Состояние проекта

Эта страница — **единственный канонический источник текущего рабочего состояния ANIMA**. Здесь хранится только то, что нужно для продолжения работы сейчас. История изменений остаётся в Git, архитектурные причины — в ADR, показательные проверки — в разделе тестирования.

## Сейчас

- Версия прототипа: **00.1-alpha**.
- D0 — Documentation: **Complete**.
- Stage 0 — Foundation: **Complete**.
- Stage 1 — Cognitive Memory: **Planned / пересматривается перед стартом**.
- Последний реализованный шаг: **SW-07**, терминальный CLI вынесен в `anima/interfaces/cli.py`.
- Fast/Deep: направление принято, моделей в коде пока нет.
- Эмоции, цели, сон, агентный слой и аппаратные узлы пока не реализованы.

## Текущая работа

Перед началом Stage 1 выполняется ревизия процесса разработки:

1. упростить систему документации и убрать дублирование статусов;
2. ввести единые правила тестирования и сохранения показательных результатов;
3. пересмотреть roadmap и критерии завершения каждого этапа;
4. определить необходимый уровень наблюдаемости и момент, когда действительно понадобится GUI отладки.

После этой ревизии Stage 1 должен получить обновлённые критерии, набор проверок и первые конкретные задачи.

## Что уже доказано

Foundation выдерживает базовые сценарии перезапуска, переноса внешнего каталога данных, сохранения `instance_id`, восстановления истории и штатного завершения сессии. Показательная проверка перенесена в [Test Results](../07_EXPERIMENTS/Test_Results.md).

## Известные ограничения

- нет постоянного набора модульных/интеграционных тестов как отдельной test suite;
- память пока основана на простом фильтре непустого текста и JSONL-хранилище;
- `identity.json` ещё не имеет полного набора правил валидации/конкурентного доступа;
- отдельный runtime/controller слой между жизненным циклом и интерфейсами ещё не выделен;
- модели Fast/Deep, когнитивный сон, внутренние состояния и действия отсутствуют;
- GUI отладки отсутствует и пока не считается обязательным.
