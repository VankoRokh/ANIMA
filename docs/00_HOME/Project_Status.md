## Известные ограничения

- EpisodicMemory читает events.jsonl. Надписи Memories stored и Recent memories в main.py описывают сырой журнал.
- identity.py пуст; состояние сессии не заменяет полноценную идентичность.
- interfaces/cli.py пуст; весь пользовательский интерфейс находится в main.py.
- Состояние JSON переписывается без атомарной замены, проверки схемы и восстановления повреждённого файла.
- Путь data зависит от текущей рабочей папки; run.sh фиксирует её на корне проекта, но конфигурации пути ещё нет.
- Прерывание до штатного сна может оставить status: awake.
- Фильтр проверяет непустой текст, а не смысловую значимость.
- Нет постоянного набора модульных тестов, моделей и сетевой синхронизации.

Подробности и задачи: [Repository Audit](../03_SOFTWARE/Repository_Audit.md) и [Backlog](../06_ROADMAP/Backlog.md).
