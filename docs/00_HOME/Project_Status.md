# Состояние проекта

Эта страница — **единственный канонический источник текущего рабочего состояния ANIMA**. Здесь хранится только то, что нужно для продолжения работы сейчас. История изменений остаётся в Git, архитектурные причины — в ADR, показательные проверки — в разделе тестирования.

## Сейчас

- Версия прототипа: **00.1-alpha**.
- D0 — Documentation: **Complete**.
- Stage 0 — Foundation: **Complete**.
- D1 — Runtime, Tests & Observability: **Complete**.
- Stage 1 — Cognitive Memory: **Planned / следующий этап**.
- Runtime отделён от терминального интерфейса.
- Поддерживается headless execution через `ScenarioRunner`.
- Постоянный pytest regression suite: **49 тестов** на момент закрытия D1.
- Доступны structured snapshot, diagnostic trace и базовые timing/CPU/RAM metrics.
- Fast/Deep: направление принято, моделей в коде пока нет.
- Эмоции, цели, когнитивный сон, агентный слой и аппаратные узлы пока не реализованы.

## Текущая работа

D1 завершён. Следующий этап — Stage 1, Cognitive Memory.

Перед реализацией новых когнитивных механизмов необходимо уточнить архитектуру памяти и критерии её проверки:

1. определить модель извлечения релевантного опыта;
2. сохранить проверяемое происхождение выбранной памяти;
3. ограничить объём контекста;
4. определить baseline и сценарии тестирования до внедрения более сложных моделей;
5. сохранить совместимость с существующими runtime, observability и regression-инструментами.

## Что уже доказано

Foundation выдерживает базовые сценарии перезапуска, переноса внешнего каталога данных, сохранения `instance_id`, восстановления истории и штатного завершения сессии.

D1 дополнительно доказал, что:

- жизненный цикл ANIMA может выполняться независимо от CLI;
- один сценарий можно воспроизводимо запускать headless;
- CLI и headless дают эквивалентное итоговое состояние;
- Stage 0 свойства защищены постоянным regression suite;
- выполнение системы можно наблюдать через snapshot, trace и базовые runtime metrics;
- тестовая инфраструктура работает на изолированных данных.

Показательные проверки сохранены в [Test Results](../07_EXPERIMENTS/Test_Results.md).

## Известные ограничения

- память пока основана на простом фильтре непустого текста и JSONL-хранилище;
- `identity.json` ещё не имеет полного набора правил валидации/конкурентного доступа;
- модели Fast/Deep, когнитивный сон, внутренние состояния и действия отсутствуют;
- GUI отладки отсутствует и пока не считается обязательным.
