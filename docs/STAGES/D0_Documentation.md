# D0 — Документация и воспроизводимость проекта

**Исторический статус:** завершено (`Complete`). **Относится к:** системе сопровождения разработки, не к когнитивным способностям ANIMA.

## Исходная задача

До D0 знания о проекте были распределены между чатами, ранними каталогами и документами с повторяющимися статусами. Стадия должна была сделать состояние проекта понятным без памяти автора или помощника.

## Что было реализовано

- Git-репозиторий становится источником истории кода и архитектурных решений; Markdown — доступным человеком форматом документации.
- `docs/project.json` хранит исторические стадии, зависимости и фокус; `scripts/update_docs.py` формирует из него обзорные блоки, не изменяя ручной текст.
- `docs/TESTING/Results/TV-*.md` сохраняют воспроизводимые свидетельства с результатом и снимком кода; индекс результатов формируется из метаданных.
- `scripts/check.sh` проверяет достижимость страниц, локальные ссылки и якоря, актуальность автосводок, ссылки на файлы и синтаксис.
- `ARCHIVE` и Git сохраняют предыдущие редакции; документы не нужно переписывать, чтобы показать новую архитектуру.

## Что проверяли

Миграцию старой документации, генерацию без дрейфа, обнаружение битых ссылок, несовместимых статусов и испорченного синтаксиса. **Основное свидетельство:** [TV-0003](../TESTING/Results/TV-0003.md); архитектурное основание — [ADR-004](../DECISIONS/README.md#adr-004).

## Граница результата

D0 подтвердил **процедуры**, а не неизменность выбранной тогда структуры каталогов. Появление релизов и независимых исследований требует новой навигации без потери старых отчётов. Актуальные правила — в [эксплуатации](../OPERATIONS/README.md#ведение-документации).
