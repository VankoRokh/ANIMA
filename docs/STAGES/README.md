## Что после Stage 6

Старые Stage 7–11 в [историческом реестре](../ROADMAP/README.md#исторический-реестр-этапов) остаются **намерениями**, а не обязательным списком работ до v0.1. Принятая семантическая граница Stage 7 имеет отдельные исследования, но полный Knowledge lifecycle официально `Planned`. Лаборатории Memory M0–M6-B2 и VAL описаны в [исследованиях](../RESEARCH/README.md).

## Как пользоваться

- Нужно понять **путь разработки** → эта хронология и страницы стадий.
- Нужно понять **текущее устройство** → [архитектура](../ARCHITECTURE/README.md) и её тематические разделы.
- Нужно понять **что именно принято в версии 0.1** → [релизы](../RELEASES/README.md).
- Нужны **исходные свидетельства** → [тестирование](../TESTING/Results/README.md).

Прежние описания из старых редакций доступны через [архив и Git](../ARCHIVE/README.md). Страницы стадий сводят факты, **не заменяют** первичные отчёты.
