# Stage 5 — FAST и граница детерминированного мышления

**Исторический статус:** завершено (`Complete`). **Назначение:** вернуть LLM роль сменного обработчика, а формальные решения оставить системе.

## Основные результаты

1. **Canonical IR:** стандартизованное представление задачи отдельно от словесного запроса и внутреннего текста модели.
2. **Детерминированный resolver:** сначала пытается получить точный результат, явно фиксирует отсутствие данных или отдаёт нерешённый когнитивный остаток. Точные вычисления не передаются модели без необходимости.
3. **Projection:** ограниченный контекст превращается в проверяемый запрос к выбранному когнитивному backend. Модель не получает постоянных прав на базу данных и исполнение.
4. **FAST:** получает проектированный запрос, возвращает `CognitiveProposal` / ответ, который валидируется системными правилами.
5. **Замена backend:** FAST — интерфейс, а не фиксированная модель или личность. Наличие LLM не требуется для формальной ветки.

## Подтверждение

[TV-0043](../TESTING/Results/TV-0043.md) описывает seven-case projected smoke с реальной Qwen3-0.6B и `llama.cpp`, а также deterministic/failure проверки. **Оговорка первичного отчёта:** точный чистый Git snapshot тогда не был записан; PASS относится к условиям указанной рабочей копии и не доказывает широкий процент правильных ответов модели.

## Граница

Этап не вводил отдельного самостоятельного FAST-планировщика и не давал LLM права завершать Goal или подтверждать Knowledge. Качество свободных ответов, multi-turn reasoning и полезность моделей должны измеряться отдельно; первые benchmark различаются по задачам и не должны смешиваться.
