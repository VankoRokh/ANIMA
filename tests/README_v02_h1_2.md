# ANIMA v0.2 — H1.2 / Finalized Raw Event Integrity

**Статус:** исправление внесено в рабочую ветку, требуется прогон на ноутбуке.  
**Ветка:** `work/v02-h1-finalized-raw-integrity` (основана на H1.1).  
**Основание:** R1-S1 N9, пропажа Raw Event при сохранённой записи `event_processing.done`.

## Контракт

Raw Event, которому соответствует финализированная запись обработки (`done` или `skipped`), не может незаметно исчезнуть из доступного журнала.

При `EventProcessingCoordinator.recover()`:

1. Исходный `events.jsonl` загружается и проверяется по существующим правилам (включая H1.1).
2. В SQLite считываются финализированные записи **того же `processor` и `processor_version`**.
3. Их Event ID сравниваются с полным набором прочитанных Raw Events.
4. При недостающем ID генерируется `ValueError("Missing finalized raw event(s) ...")` с детерминированным ограниченным примером Event ID.
5. **До этой проверки** не допускаются `_bootstrap_missing`, повторная проекция или новые события через `Runtime.wake()`.

Это **fail-closed**, а не автоматическое исправление. Raw журнал и финализированные строки SQLite не изменяются при таком обнаружении. Система не выдаёт `context` или `search_events` со статусом нормальной работы в проверяемом пути `open_release`.

## Что изменено

## Границы гарантий и дальнейшая работа

- Проверяются `done/skipped` текущей пары `processor/processor_version`. Другие версии, ручные `memory_sources` без ledger и произвольные отношения Knowledge остаются отдельными контрактами.
- Проверка производится **при Recovery**, а не непрерывно после каждого изменения файлов. Внешняя правка raw посреди уже открытой сессии не входит в эту гарантию.
- Сверяются **Event ID и доступность валидного Raw Event**, но не неизменность всех исторических байтов при подмене содержимого под прежним ID. Этот риск относится к H1.3 (N6) и дополнительной модели целостности.
- Полное чтение EventLog в Recovery уже присутствует в v0.1. Сверка добавляет сравнение финализированных ID и запрос SQLite; производительность на больших журналах потребует измерений.
- **Не** выполняются автоматическая реконструкция Raw, удаление записей, миграция SQLite, признание намеренного удаления или исправление осиротевших Relations.
- Утрата источника может требовать отдельной процедуры восстановления из резервной копии. Релиз не должен самостоятельно угадывать или фабриковать свидетельство.
